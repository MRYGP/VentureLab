# 当前阶段：产品眼力训练与行动触发

> 日期：2026-08-27
> 状态：杨阶段判断的执行沉淀
> 适用范围：方向 B 当前产品观察、即时灵感与尚未进入项目第 0 步的支线
> 不改变：证据标签、三道门、TradeLab 权限、外部行动授权和方向 A 状态

## 一、当前到底在做什么

当前阶段的主要任务是训练杨对具体产品的判断力：从真实产品、众筹页面、使用演示、评论和交付结果中，逐渐形成对用户为什么买、产品真正改变了什么、成功依赖什么、哪里可能失败以及哪些部分值得迁移的独立判断。

这不是商业验证，也不是无意义的等待。它的价值在于降低以后选错产品、误判创新、把传播当需求或把专利当成功原因的概率。但它必须有边界，不能以“继续学习”为理由无限推迟现实行动。

当前尚未发生的事实仍须诚实保留：没有外部询问、授权、报价、拿样、发布、付款、拒绝或退款。学习进展与商业进展分开记账，前者不得冒充后者。

## 二、对前期系统建设的判断

前期规则并非全部空转。

- 证据标签和来源纪律已经拦截零 URL 报告、ASIN 混淆、构造链接、“美国实用新型专利”等错误；
- 杨先观察、代理后补充的顺序已经在 ColorNow 和 V1 Pro 中留下了不可事后改写的判断；
- “抄不作为最终成果”“美国专利不能直接在中国维权”等边界减少了错误行动风险。

真正需要停止的是：每看一个产品就立即调用三道门、案例编号、假设账本、晋级单和 TradeLab。经营决策系统只在杨明确选中一个值得测试的对象后启用，不负责管理每一次学习。

因此，现行系统不是废弃，而是**待触发**：学习期不逐条调用，进入行动期时再启用。

## 三、两个工作模式

### 模式 L：学习与观察（当前模式）

```text
平台或生活中看见具体产品
  → 杨先说第一印象、购买者、差异与失败猜测
  → Codex 再补页面事实、评论、Updates、交付和替代解释
  → 对照事前判断，记录哪里看对、哪里看错、哪里仍为 Ø
  → 提炼可迁移的观察，不自动生成候选
```

模式 L 中：

- 不要求每个产品通过发现门；
- 不建立 C 编号、B-H 编号或 TradeLab 候选；
- 不因为一个产品暂停就把它视为失败；
- 不因最新灵感暂停正在拆解的产品；
- 不用文件数、采集数和模型共识计算进展。

### 模式 A：项目与行动（触发后启用）

出现以下条件时，才从观察进入项目第 0 步：

1. 杨明确说“这个对象或路线值得从理解转向验证”；
2. 能点名一个具体产品、目标人群／合作方和目标市场；
3. 能说清下一条外部动作是什么，例如询问、拿样、报价、预售或渠道测试；
4. 杨愿意为该动作分配明确的时间、现金或对外授权。

进入项目第 0 步后，才根据项目性质调用三道门、假设账本和 TradeLab。观察材料可以成为输入，但不得反向写成项目已经成立。

## 四、支线的处理原则

杨容易从具体材料中产生支线，这是寻找更近路线的一部分，不应压掉。代理已验证产品、跨境市场进入、外国品牌在中国的知识产权运营、一次性指套和包桌迁移，目前都属于这一层。

支线在未进入项目第 0 步前只保存五项：

1. 原始触发；
2. 杨看见了什么；
3. 为什么它可能比当前路线更近；
4. 当前最大未知；
5. 什么事实出现后值得进入项目第 0 步。

支线不自动获得方向编号，不进入主任务队列，不要求立即深研，也不因暂时不行动而删除。它们是未来路线的补充输入，不是当前承诺。

“代理已验证产品＋市场进入”当前保留为一条支线观察；“知识产权保护运营”只作为该支线可能的增强能力。两者均不建立方向 C、不新建仓库、不启动外部联系。

## 五、当前学习周期的复盘点

“看够了再行动”必须有可见边界。当前第一学习周期在满足以下任一条件时复盘：

- 累计完成 10 个由杨先开口的具体产品观察；或
- 其中至少 3 个走完“筹款／产品页 → 评论 → Updates／交付 → 结果对照”的完整学习闭环；或
- 杨在周期中提前点名一个值得进入项目第 0 步的对象。

复盘只回答四个问题：

1. 杨反复看见了哪些用户动作、产品机制和成功条件？
2. 哪些事前判断被结果反复推翻？
3. 是否出现一个杨愿意亲自验证的具体对象或合作路线？
4. 下一周期是继续学习、换平台，还是启动一次外部动作？

如果仍无具体对象，可以继续第二学习周期，但必须改变平台、品类或观察问题之一，不能原样重复采集。
