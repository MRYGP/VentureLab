# AI 应用实习生申请说明与首轮问卷

版本：v0.5
日期：2026-09-21
用途：候选人申请说明，可直接放入飞书链接并对外发送

## 一、先了解这份实习

- 公司：湖南旻召新材料科技有限公司
- 岗位：AI 应用实习生
- 地点：长沙市雨花区树木岭，以线下协作为主
- 薪资：150—200 元／天，按实际出勤计算，一月一结
- 时间：原则上每周累计不少于 4 天，接受半天出勤；希望连续实习不少于 3 个月
- 招聘人数：计划招聘 1 至 2 人

我们希望招聘能够主动学习、实际动手并把事情推进到结果的实习生。本岗位不做大模型训练和算法研究，重点是使用成熟 AI 工具、开源项目和现实调研解决真实问题。

岗位设两个主方向。申请时可以选择自己的优先方向；最终主方向将结合个人偏好、既有经历、面试表现和当时的真实任务共同确定。每位实习生以一个方向为主，同时参与必要的共同研究和协作，不要求一个人同时精通全部工作。

### 方向一｜AI 应用与 Agent 落地

主要工作：

- 学习和实测 Codex、ChatGPT、Claude Code 等 AI 工具；
- 部署、测试和拆解公开的 GitHub 项目，处理常见环境与依赖问题；
- 为团队的真实任务比较工具、建立测试基线并记录失败样例；
- 把有效流程做成可复用的工作流、RAG、Skill 或 Agent；
- 向 1 至 2 名同事演示使用方法，说明适用场景、失败边界和人工复核点；
- 为产品研究制作必要的技术原型或内部工具。

适合有 Git、终端、编程和项目部署基础，喜欢动手、排错和制作工具的同学。

### 方向二｜产品研究与验证

主要工作：

- 寻找和初选国内外新产品，整理用户、场景、现有替代与关键未知；
- 与负责人一起形成并比较不同产品构思，不把想法直接当成需求；
- 根据具体项目寻找并联系用户、厂家、设计师或外包人员；
- 推进访谈、报价、材料、样品、起订量、交期和后续跟进；
- 协助制作数字 MVP 或推进实体产品方案；
- 记录成功、拒绝、无回复和负面结果，提出继续、修改或停止的建议；
- 使用 AI 提高资料研究、沟通准备、原型制作和跟进效率。

这个方向不要求较强的编程能力，但需要愿意接触陌生人、处理琐碎步骤，并把构思推进到现实反馈。会编程、会制作原型或有供应商沟通经历属于加分项。

### 两个方向都会接触的工作

- 产品和商业讨论；
- 资料核验、整理和必要的公众号发布；
- 真实项目中的重复性、助理性工作；
- 使用 AI 提高团队的研究、协作和执行效率。

## 二、你可能获得什么

这不是只看课程、写报告或完成一次演示的实习。我们希望让实习生经历“学习或发现—实际动手—取得反馈—修正方案—继续或停止”的完整过程。

选择 AI 应用与 Agent 落地方向，你将有机会：

- 在真实内部使用者和真实任务上部署、评测并改进 AI 工具；
- 走完选择工具、安装环境、排错、建立基线、交给同事使用和根据反馈迭代的闭环；
- 形成可复现的部署记录、Agent／工作流、RAG 原型或经脱敏后可写入简历的项目案例。

选择产品研究与验证方向，你将有机会：

- 参与从产品线索、用户研究和产品构思，到 MVP、样品或停止决定的完整过程；
- 接触真实用户、供应商、设计和制作资源，而不是只写市场分析；
- 稳定交付后，逐步独立负责一次小型产品研究与验证任务，并形成经脱敏后可展示的完整案例。

两个方向都会直接与需求提出者协作，看到一项工作为什么继续、修改或停止。小团队没有大公司的成熟培训体系，任务也可能根据验证结果变化；相应地，你会获得更短的反馈链和更完整的任务视角。

这里不承诺共同创业、合伙人身份、股权、转正或项目一定成功。能够承诺的是清楚的报酬、真实的任务和直接的反馈。

## 三、请先确认共同条件

请在继续作答前确认，你目前基本符合以下条件：

1. 目前是在读大四学生或在读研究生；
2. 能够阅读英文产品资料或技术文档；CET-6 已通过可作为申请阶段的初步证明，未通过者也可以在面试中通过统一的英文技术资料现场测试证明符合；
3. 能到长沙市雨花区树木岭线下协作；
4. 每周能够稳定投入累计不少于 4 天，半天可以累计；
5. 能够连续实习不少于 3 个月；
6. 接受 150—200 元／天、按实际出勤计算、一月一结；
7. 使用过 ChatGPT、Claude、Codex 或其他 AI 工具，并愿意持续学习；
8. 能接受真实任务中的助理性、重复性和跟进工作；
9. 愿意如实说明不知道、没做过、跑不通或验证后不值得继续的情况。

如果除 CET-6 证书以外的上述任一项明确不符合，请不必继续答题或投递简历，避免浪费双方时间。如果只是未通过 CET-6，但能够阅读英文产品或技术资料，可以继续申请，并如实填写证书状态；所有进入面试的候选人都需要接受实际阅读能力核验。如果只是个别时间安排尚未最终确定，也可以如实说明，不需要为了通过筛选而给出确定答案。

### 方向一的基础要求

- 使用过 Git、终端和环境变量；
- 至少一门编程语言能够读、改和调试；
- 至少亲自部署或排查过一个真实的 GitHub 项目。成功或失败都可以，但需要说明自己做过什么、遇到什么问题、如何验证。

### 方向二的基础要求

- 能把模糊任务拆成具体对象、下一步动作和需要记录的信息；
- 愿意通过公开渠道联系用户、厂家或其他合作对象，并接受拒绝与无回复；
- 能说明至少一次自己把一件事从想法推进到外部真实结果的经历。可以是用户访谈、活动组织、社团招募、销售、客服、供应商沟通、个人项目或其他经历；结果可以失败，但不能只有方案或 PPT。

## 四、作答说明

- 完整阅读与作答通常需要 20—30 分钟，请在时间合适时开始，并简洁、真实地回答。我们每天会收到较多招呼，这份材料本身也是第一轮投入与匹配筛选，不追求所有打招呼者都完成。
- 这些题没有统一的“标准答案”。我们更关心你实际做过什么、怎样判断，以及面对不确定时是否诚实。
- 可以使用 AI 帮助整理语言，但不能让 AI 虚构经历。凡写入答案的事实和判断，都需要你在面试中解释、追溯和接受新条件下的追问。
- 不需要为了申请免费联系真实用户或厂家，也不需要制作可直接用于我们的产品或 MVP。
- 不要提交身份证号、家庭住址、银行卡、账号密码、API Key、未公开代码或原单位／学校的保密材料。

## 五、首轮问卷

### Q1｜基本信息与时间

请填写：姓名、BOSS 昵称、学校、专业、学历与年级、预计毕业时间、目前所在城市、手机号码；最早可到岗时间、最晚能连续实习到什么时候，预计每周可投入的整天和半天数量，以及 CET-6 状态（已通过／未通过／尚未参加）。

请同时逐项确认第三节的 9 项共同条件，回答“符合／不符合／尚未确定”，必要时补充说明。

### Q2｜方向选择

请选择自己的优先方向：

- 方向一：AI 应用与 Agent 落地；
- 方向二：产品研究与验证；
- 两个方向都愿意了解，但请写明当前更优先的一个。

请用 100 字以内说明选择理由，并说明是否愿意用少部分时间配合另一个方向的工作。

### Q3｜简历与作品

请附一页简历。若有 GitHub、个人作品、技术文章、公开演示或其他能够说明真实经历的链接，也请一并提供；没有公开链接不会直接淘汰。

### Q4｜一项与主方向相关的真实经历

**选择方向一的申请者回答：**

请选择一个自己亲自部署或排查过的公开项目，说明项目名称与链接、使用环境、你亲自完成的动作、一个具体报错或卡点，以及你怎样确认它真的跑通或为什么决定停止。建议 180 字以内。

**选择方向二的申请者回答：**

请选择一次自己把事情从想法推进到外部真实结果的经历，说明目标是什么、你实际联系或协调了谁、遇到过什么拒绝或变化、你做了哪些动作、最终结果是什么。

请尽量附上一项可追溯的痕迹，例如早期版本、匿名沟通记录、报名或到场数据、供应商报价或对比表、销售记录、交付物。涉及他人信息请脱敏。确实没有留存材料的，请直接说明原因，不要为了申请临时补做或编造。建议正文 180 字以内。

### Q5｜最近一次真实使用 AI 完成任务

请写最近 30 天内的一次真实经历：任务是什么，使用了什么工具，AI 完成了哪一部分，你保留了哪些人工判断，又如何检查结果。建议 150 字以内。

### Q6｜方向情境题

这是一个假设情境，只需要说明你的思考和行动方法，不要把没有真实发生的动作写成个人经历。

**选择方向一的申请者回答：**

给你一个从未使用过的 GitHub 项目，希望你在 3 天内判断团队是否值得采用。第一天你会按什么顺序做哪些动作？什么结果会让你建议停止？建议 150 字以内。

**选择方向二的申请者回答：**

团队有一个还比较模糊的产品想法，希望你在 3 天内取得第一批现实反馈。第一天你会找谁、做什么、记录什么？什么结果会让你改变方案或建议停止？建议 150 字以内。

### Q7｜一次失败、改变或停止

请写一次自己投入时间后仍未做成，或者根据新信息主动改变方法或停止的经历。你在什么时候意识到原方法不再值得继续？如果重来，会提前检查什么？建议 120 字以内。

### Q8｜你的预期、AI 使用披露与反问

请说明：

1. 三个月后，你希望自己留下什么可以验证或展示的成果？
2. 本次回答是否使用了 AI；如果使用，AI 参与了哪一部分？
3. 你现在最想向我们确认的一个问题是什么？

建议合计 150 字以内。
