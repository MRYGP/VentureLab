## 一、统一评分口径

### 1. 单项分数

| 分数 | 含义 |
|---:|---|
| 1 | 基本没有证据，或已出现明显反向信号 |
| 2 | 有合理性，但关键证据仍缺失 |
| 3 | 有初步行为、样品或交付证据，仍未稳定 |
| 4 | 有较强的同位市场或重复执行证据 |
| 5 | 有稳定、可复核、可重复的真实交易与交付证据 |

### 2. 证据置信度

| 等级 | 含义 |
|---|---|
| E0 | 无直接证据 |
| E1 | 主要是推断、单一来源或相邻市场材料 |
| E2 | 有内部行为、样品、实际执行或多条有限证据 |
| E3 | 有可复核、重复出现的同位真实市场行为 |

### 3. 综合档位

| 档位 | 含义 |
|---|---|
| A | 已验证的扩展候选；付款、交付、单位经济和责任边界均有重复证据 |
| B | 可以进入一次有上限的真实交易验证 |
| C1 | 有价值可能，但关键商业证据缺失；最多只值得一次封顶判错实验 |
| C2 | 主要停留在构思或原型层，当前不值得购买下一条昂贵证据 |
| D | 已出现致命反证或明确停止条件 |

### 4. 四道硬门

以下四项不能被创意、原型完成度或低验证成本抵消：

1. 同位付款；
2. 非创始人特例的真实交付；
3. 单位经济；
4. 责任与合规边界。

归一规则：单项先看各评估者的分布和分歧，再给保守整数；不跨维度相加。综合档位受硬门约束。Agent 共识不是 `F-M`，最终是否行动由杨裁决。

## 三、KAIROS 评分卡

### 3.1 中性构思说明

KAIROS 不是一本完整回忆录，而是一项高客单、低频、强信任的定制内容服务：通过访谈、资料校准、剧本、真声和 H5 等形式，重建主人公人生中一个关键决断时刻，让家人、接班人或其他重要受众理解“他当时为什么那样选择”。现有《2011·那只水杯》证明样品和部分制作方法存在，但尚未证明陌生主人公愿意付费、非杨案例可稳定交付、29,800 元价格下单位经济成立，或第三方叙事与声音权边界已闭合。

### 3.3 已达成的共识

1. **同位付款为 1 分，且是 E0。** 29,800 元总价和 5,000 元定金只是内部候选价格；没有真实报价、签署或到账。

3. **获客依赖高信任入口。** 四份评估均未发现已存在的暖名单或可重复渠道。
4. **责任边界尚未闭合。** 第三方名誉、隐私、商业敏感信息、主人公确认权、传播范围和声音权都需要正式设计。
5. **它不是应立即恢复的项目。** 当前最多保留一次有上限、以付款为先的判错选项。

### 3.6 当前最有裁决力的实验草案

这是 Agent 建议，不是杨已批准的行动。仓库当前仍禁止主动联系、报价、收款或售卖，除非杨另行明确授权。

**实验名称：锁定付款角色的首笔真实定金实验。**

- 原样使用现有《2011·那只水杯》H5，不新增非杨样片，不先投入完整制作。
- 预先分成三组：主人公本人、子女／家庭、企业／公司账户；各组使用与其角色一致的触发事件和合同抬头，结果分账，不把三种产品混成一个转化率。
- 总上限为 12 次合格销售开口、6 周、外部现金不超过 3,000 元、杨人工时间不超过 40 小时。
- 正式报价口径暂用总价 29,800 元、定金 5,000 元；只有真实到账才算付款行为。
- 为避免收了多笔定金却无能力履约，销售在首笔合格定金到账后立即暂停；先完成一个非杨付费交付并记录全部工时、改稿、争议、授权与贡献毛利，再决定是否测试第二笔。
- 0/12 到账：当前版本封存，不通过改 H5 或换一种说法立即重试。
- 1/12 到账：只证明存在一笔同位付款，不证明渠道、重复性或规模；必须先履约，不能直接升级为 B 或扩大销售。
- 无论结果如何，所有合同承诺和退款义务必须履行；“商业判断失败”不能成为不履约的理由。
