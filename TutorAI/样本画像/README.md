# TutorAI 样本画像

本目录保存三个孩子的**脱敏、动态研究画像**。画像不是性格判决、医学判断或一次性标签，只用于帮助选择下一次兴趣研究入口，并随新行为证据修订。

## 记录层级

- `F-P·当前`：杨或孩子近期提供的家庭事实／观察；仍不能外推到其他孩子。
- `F-P·历史`：旧仓、旧复盘或旧方案中的记录，必须带日期；不能默认今天仍成立。
- `H·旧方案`：旧计划对孩子的判断或培养设想，不是实际行为结果。
- `I`：根据多条材料形成的暂时解释。
- `H`：准备通过下一次观察检验的假设。
- `Ø`：目前不知道。

若历史文件互相冲突，两个版本都保留并登记冲突，不替孩子选择“真正性格”。“懒”“不聪明”“内向”“自律差”等概括词必须翻译成具体情境、任务和可观察行为后才能进入研究。

## 每次更新的最小结构

1. 新发生了什么；
2. 是孩子自发行为、家长观察，还是计划者解释；
3. 支持或削弱了哪个假设；
4. 下一次只改变哪个参数；
5. 哪些旧判断因此过期。

## 隐私边界

不记录真实姓名、学校、班级、住址、联系方式、账号、原始作业、手写图像、语音及健康／发展细节。需要这些信息时只在家庭私域处理，不进入公开仓。
