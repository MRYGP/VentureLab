## 使用纪律

1. 图片用于强制选择与发现明显反感，不把“觉得好看”写成需求成立。
2. 比较版本时保持画面质量、信息量和价格条件接近，避免某张渲染图因为更精致而假胜。
3. 任何新图都要标明它验证的是购买冲动、礼物个性化、时间任务、笔载体、旋转还是材质，不能一张图同时证明全部。
4. 第三方商品图不得放入本目录；对标只保留 URL 与核验记录。
5. 进入结构、供应商或销售验证前，先按主记录第十九节攻击最可能的三个死法。
