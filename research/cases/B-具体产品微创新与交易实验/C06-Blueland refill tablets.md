# C06-Blueland refill tablets

- 具体产品：Blueland Hand Soap Starter Set 与 refill tablets
- 品类与国家/市场：家庭清洁与洗手液补充系统；美国市场

## 3. 改良机制

- 主改良变量：成本结构
- 一句话改良：让消费者在使用地加水，以永久容器配干燥 tablet，减少运输水和重复容器。
- 次变量与潜在混杂因素：环保叙事、包装、DTC、订阅、Costco/Target/Whole Foods 渠道。
- 买家何时、如何感知差异：购买前可理解“装水、投片、溶解”，首次使用即可验证补充流程。
- 是否可被快速复制：`I`：tablet 与永久瓶结构可见，但配方、品牌、零售关系和订阅留存的复制难度未核。
