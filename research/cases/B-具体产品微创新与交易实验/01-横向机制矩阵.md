## 用户拉力与行动门（2026-08-25 裁决）

### 三种销售形态

| 类型 | 定义 | 研究重点 |
| --- | --- | --- |
| P1 爆发型 | 短期购买速度高，可能快速衰减 | 峰值来源、异常放大器、仿制速度与库存风险 |
| P2 持续畅销型 | 跨较长时间保持购买与供给 | 持续时长、价带、复购、渠道与竞争变化 |
| P3 安静长销型 | 没有明显爆发事件，普通渠道持续动销 | 普通经营者能否进入、补货与履约是否可复现 |

P1/P2/P3 是描述字段，不是高低排名。没有时间序列或精确 SKU 证据时写 `Ø`，不得从品牌故事反推。

### 五层必答问题

| 层 | 必答问题 | 不得混写 |
| --- | --- | --- |
| U1 用户拉力 | 用户在什么触发场景下，为何愿意付钱？ | 购买理由不等于产品功能清单 |
| U2 相对选择 | 为什么买它，而不是旧产品、低价同类或不处理？ | “有创新”不等于用户选择它 |
| U3 分发传播 | 用户如何看见、理解和信任它？依赖什么放大器？ | 曝光不等于需求，异常渠道不等于杨可复制 |
| U4 持续性 | 它是短期尖峰、持续畅销还是安静长销？ | 售罄／补货页面不等于长期动销 |
| U5 价值捕获 | 获客、履约、退货、库存、复制和投诉后谁留下钱？ | GMV、销量和毛利不等于实际利润 |

U3 与 U5 必须成对回答：让产品更易传播的机制，是否同时抬高获客成本、退货率、仿制速度或库存风险。

### 发现门与行动门

```text
发现门：精确 SKU + 真实购买／付款线索 + U1—U5 可回源 + 反例
  → 允许进入主体理解

行动门：用户拉力可迁移 + 分发可复现 + 今日参数可核
  + 责任边界可控 + 单位经济仍可能成立
  → 才进入抄／改良／迁移／不做判断与假设账本
```

今日参数至少包括供给、MOQ、报价、渠道规则、履约、合规、投诉与库存风险。公开报价和平台规则通常是 `F-P`；实际贡献利润在真实交易前只能是 `H/Ø`。

现金、时间、库存、合规与渠道依赖分别记录，不做跨量纲加权总分。只有实际贡献利润与峰值现金暴露都有同口径金额时，才允许计算现金回报倍数。

## 当前可保留的工作判断

1. `I`：购买前或首次使用可感知，可能降低第一次交易的解释成本，但不保证留存、利润或履约。
2. `I`：专用硬件若只减少可由手、手机或平台软件近零成本消除的步骤，替代风险较高。
3. `I`：形态越容易被理解，也可能越容易被制造端商品化；是否还能保留收益仍是全库最大 `Ø` 之一。
4. `I`：耐用品/refill 可迁移已有预算，但清洗、补充、教育和前置价格会制造新摩擦。
5. `Ø`：没有案例证明 AI 是历史成功原因；2023 年后 AI 是否真实降低产品微创新成本仍未取得合格样本。

## 下游工具：从产品复制转向非功能阻力扫描

`[新增裁决 2026-08-24]` C01 与 C02 的共同点，不是都容易演示，而是核心功能早已存在，购买和使用仍被非功能阻力卡住：

- C01：既有吸力工具难理解，主要处理认知、解释和信任阻力；
- C02：既有水胶体贴带有遮丑和医疗感，主要处理情绪、身份和公开使用阻力。

因此，对结构可见、制造简单、供应链成熟的具体产品，不能只看外形。通过用户拉力理解后，再判断直接抄是否仍有普通渠道需求，或同一种非功能阻力还出现在哪些具体场景。非功能阻力扫描是下游工具，不再是 B 线研究入口。

### 直接复制行动门

满足以下多数条件时，直接复制默认关闭，除非已有普通经营者持续成交、可核价差或杨另有已核进入优势：

1. 中国公开零售已经有同原理、同形态产品；
2. 中国制造端已有低门槛现货、贴牌或快速定制供给；
3. 价格和外形已经商品化，单纯降价或换图案无法保留收益；
4. 杨没有独有渠道、信任、合规、IP、社群、数据或履约优势；
5. 无法说清复制后仍由谁付款、为什么不选现有低价品。

“中国已有仿品”本身不证明没有市场。多个独立仿品卖家的可核成交可以加强“普通供给下仍有购买”的判断，但不能证明卖家利润；卖家多而价带持续下探也可能是负向信号。复制研究必须同时检查活跃外观专利／商标投诉和下架后的库存处置路径，`Ø` 时不得把库存默认写成可清理。

## 经营判断门

通过发现门与行动门后，第一层用于决定是否值得申请一轮封顶交易实验：

```text
用户拉力有证据 → 相对选择可解释 → 分发可复现
  → 今日参数可核 → 单一交易假设 → 可触达且责任可控
```

第二层用于决定是否值得持续经营：

```text
能重复获客 → 能稳定履约 → 被复制后仍有收益
  → 退货售后可控 → 渠道不完全依赖异常资源
```
