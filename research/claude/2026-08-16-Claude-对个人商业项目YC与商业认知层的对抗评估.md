## 一、最强钢人论证

如果我为这两份文档做最强辩护，论证是这样的：

它们没有在拼装系统，它们在做唯一必须先发生的事——**把一个不可证伪的服务，转成一个可验收的交付单位**。

"帮你找到赚钱路线"无法定价，根本原因不是营销问题，而是**不可缔约**：双方无法约定什么算交付完成，因此无法定价、无法验收、无法退款、无法追责。"推进你当前的一个项目，产出一份报价、发出去、拿到回复或明确拒绝"是可缔约的。**可缔约性是服务能否被定价的前置条件，不是包装问题**。这一步的价值不在于它更聪明，而在于它把一个无法成为商品的东西变成了可以成为商品的东西。

第二，商业认知那份文档做出了一个正确且不显然的选择：**它拒绝了做课程**。默认路径是"用户不懂商业 → 我们教商业 → 卖课"，这条路顺理成章、毛利好、可规模化、且立刻有现金流。文档明确把这条路标为危险，改为"由项目决策触发的及时补丁 + 必须形成真实产物 + 紧接外部动作"，并直接点名 `完课率替代市场结果` 这一失败模式。一个更弱的团队会去做课。

第三，两份文档的**全部**产品结论都写着 `H/Ø`，第十二/十五/十六节逐条列出"本文不决定"。按它们自陈的目的——"让后续讨论不再把五种产品混成一种"——它们成功了。批评它们"拼装了七个生意"是误读：**它们建的是一个区分装置，不是一个产品**。把互斥选项并列写清，正是防止拼装的手段。

第四，Batch 0 有一个别的方案都没有的性质：**失败不消耗任何稀缺关系，也不伤害任何真实客户**。在滩头、渠道、价格全部为 `Ø` 的状态下，唯一现成可用的实验对象就是杨自己。用它先摸清交付形状，比拿真人试错便宜得多。

**这个钢人的薄弱处在哪里**：它全部成立在"文档只是地图"这个前提上。而地图一旦足够完备，就开始承担第二个功能——为任何新想法提供一个合法的落脚格。下面三条攻击针对的正是这个功能。

## 二、三条最致命攻击

### 攻击 1｜合规剩余量为零：最有卖点的话，杨自己禁止说

这是**文件级冲突，可以直接核验**。

- YC 文档 §2.2 把加速器定义为"帮助项目取得**第一笔真实付款**、明确的市场信号，或足以停止的反证"。
- `compliance/禁止承诺与证据门槛.md` §1 明确禁止对外表述："保证赚钱、保证回本、**保证第一单**"；"陪跑到结果，除非合同精确定义结果和责任边界"；"成功率、平均窗口期"。
- 同文件 §2 列出**允许的最窄表达**：帮你比较候选路线与当前资源的缺口；明确哪些判断有证据；把候选路线改写成低成本侦察动作；预先限定时间与停止条件；不保证收入。
- 同文件 §4 结尾：不得把"过程确定性"包装成"结果确定性"。

**把两者叠加**：这个产品能合法说出口的全部卖点，是"我帮你梳理、限定和停止"。**这恰好是通用模型加一个日历能覆盖的那一格**——LLM 竞争地图 §2 自己已经把"路线生成、风险分析、个性化报告、提醒打卡、单一下一动作"全部列为可能被商品化的薄价值。

于是形成一个夹逼：**允许说的话正是被商品化的部分；有差异的话正是被禁止说的部分。** 这不是营销技巧问题，因为差异部分（拿到第一笔付款）在结构上就是 EarnPath 不能控制、也不该承诺的外部结果。

三份文档没有一处做过这个叠加检查。它们分别讨论"如何抵抗通用 LLM"和"不许承诺什么"，从未把两张表放在一起看还剩下什么。

**这条攻击可能错在哪**：合规文件是杨自愿设的高标准，不是市场准入门槛；中国市场大量同类服务在更宽松的措辞下正常经营。若杨愿意降低自我标准，这条攻击强度大幅下降。但那时要重新裁决的是责任与信誉，不是文案。

### 攻击 2｜Batch 0 无法测试它要测的东西

YC 文档 §9.2 列出 Batch 0"可以证明"六项。逐项检查会发现一个结构性漏洞：

YC 类比中被认为**可迁移**的机制，核心是两条：**筛选**（H-YC-02、§5 用户与项目准入）和**批次同侪**（§3.1 表中"同批创始人"）。

- **筛选的全部价值在于区分录取与拒绝。** Batch 0 的样本量为 1，且这个样本必然录取。筛选环节在 Batch 0 中**完全未被执行**，因此完全未被测试。
- **同侪机制在 N=1 时不存在。** 没有第二个项目，就没有比较、没有压力、没有横向反馈。

所以 Batch 0 能测的，只有：单项目聚焦、时间盒、停止线、AI 辅助分析、外部触达执行。而这五项，正是 LLM 竞争地图 §2 已经登记为"可能被通用模型和现成工具低成本复现"的那一层。

**结论**：Batch 0 只能验证已知薄弱的部分，无法验证被主张为差异的部分。它产出的任何正面结果，都不能支持"个人 YC"这个类比。

更进一步：Batch 0 的项目就是"卖 EarnPath"。所以"Batch 0 成功"= 有人为 EarnPath 付款 = E001 的结论。**批次外壳没有增加任何证据，只增加了叙事。** 而叙事的副作用是：搭建加速器机制（写卡片、定阶段、设准入）本身会被记为"Batch 0 的项目进展"，形成一个可以无限运行的合法闭环。文档 §9.4 用一张检查清单预防自证循环，但清单不是结构性约束——**结构性约束应当是：Batch 0 只有一个成功指标（一笔非人情付款），其余全部产物默认是待删除的脚手架。**

### 攻击 3｜EarnPath 不通过它自己写的项目准入门槛

YC 文档 §5.3 列出项目硬门槛。用它检查 EarnPath 自己：

| 2. 可以找到第一批同类对象 | **不通过** `Ø` | `E001` 触达渠道及权限 `Ø` |
| 3. 可以先手工交付 | 通过 | — |
| 4. 有限周期内获得报价／拒绝 | 待定 `H` | 依赖 2 |

| 8. 能多完成一段通用模型难以完成的闭环 | **未证明** `H` | LLM 地图全篇待验 |

同时检查 §5.2 人的硬门槛第 3 条"**愿意销售**：愿意接触真实客户、报价、被拒绝并追问原因"——这一项在杨身上当前登记为 `Ø`：仓库显示三轮竞品研究和三份假设地图已完成，而联系真人、报价、收费全部处于"未授权、未启动"。此外，据杨自述的历史（`F-P`，杨自述，本轮未在仓库核验），过往多份高质量项目提案均未推进到真实客户付款。

**这条攻击的力量不在于"杨不合格"，而在于一个二选一**：

- 若准入门槛是真的，它应当**第一个咬住 EarnPath 自己**，结论是 Batch 0 现在不该跑，应先补第 1、2 项；
- 若准入门槛不咬 EarnPath，那它对未来客户也不会真咬，它是**装饰性筛选**，YC 类比中"筛选可迁移"这一条随之失效。

两条路都指向同一个动作：**先解决"第一批人从哪来"，而不是先解决"怎么服务他们"。** 而两份新文档 90% 的篇幅在解决后者。

**补充：一个我认为被严重低估的实务问题。** 批次制的最小可售单位是**一个批次**，不是一个客户。同侪、比较、Customer Day 都需要 N≥6 同期。这意味着批次形态的冷启动门槛比一对一咨询高一个数量级——**恰好在渠道为 `Ø` 的时刻，文档选择了对渠道要求最高的形态**。

## 三、YC 可迁移／不可迁移表

| YC 机制 | 可迁移性 | 我的判断（与 Codex §3.1 的差异） |
|---|---|---|
| 股权 / 幂律回报 | **不可迁移** | Codex 同意。补充：YC 可以 90% 判断错误仍然盈利；**收费服务模式对每一个付款客户都必须做对**。风险承受结构被反转，机制不能脱离它借用 |
| 资本 / 后续融资分发 | 不可迁移 | 同意 |
| 品牌与身份信号 | 不可迁移 | 同意 |
| 投资人网络 → "买方网络" | **不可迁移，且翻译失败** | **与 Codex 分歧**。Demo Day 成立的前提是存在一个**有预算、有配置义务、以看早期项目为职业**的买方阶层。个人小生意的客户没有任何义务出席、没有配置压力、看一堆未验证项目对他们是纯成本。Customer Day 应从可迁移清单**移除**，不是标 `H` |
| 筛选 / 大量申请带来的选择权 | **不可迁移** | **与 Codex 分歧**。Codex 标 `H`。我认为筛选是资本与品牌的**副产品**：YC 能筛是因为三万人申请。申请人为 0 时，"筛选"不是选择权，是给销售增加的摩擦。应重标 `Ø→不成立`，除非先出现供给过剩 |
| 校友网络 | 不可迁移（长期 `Ø`） | 同意 |
| 批次同侪 | **理论可迁移，冷启动不可行** | 最小可售单位 = 一个批次（N≥6 同期）。渠道 `Ø` 时结构性不可执行。第一阶段应删除 |
| 固定 Partner + 高频 Office Hours | **可迁移，但等于人工咨询** | 这是本表中唯一无争议可迁移的机制，代价是它把形态拉回"一对一顾问"，同时**取消了批次的规模化理由** |
| 一次只推进一个主要问题 | **可迁移，但零壁垒** | 免费、可复制、通用模型 + 日历即可实现。它是好纪律，不是资产 |
| 固定周期 + 外部里程碑 | **可迁移，但零壁垒** | 同上。真正稀缺的是"到期必须交外部证据"这条被第三方执行的约束 |
| 三个月全职集中 | **不可迁移** | 目标用户是业余时间。YC 的强度效应依赖全职，兼职版本的效力从未被验证 |

**净剩余**：去掉资本、股权、品牌、校友、投资人后，YC 只剩下**"固定顾问 + 单一焦点 + 时间盒 + 到期交外部证据"**。这四条加起来，是一个成熟且古老的行业：**business coach / 生意教练**。这不是坏消息，但它意味着 YC 类比的实际信息量接近零——它没有指向新东西，只是给一个已存在几十年的形态换了个更兴奋的名字。**建议把"YC"从内部类比中也降级**，改用"一对一生意教练 + 强制外部动作"作为工作命名，因为后者能直接找到活体对标、真实单价和真实获客方式。

| 预备营 / 低价准备层（§11） | **删除** | 这是知识付费的标准滑坡入口。一旦存在，它会因为最容易卖而挤占全部注意力 |
| 免费公开基础课作获客（§11） | **延后** | 内容获客需要长期积累 + 分发，是另一门生意（媒体）。现在做等于同时开两家公司 |

## 六、当前实际包含的不同生意及其相互冲突

两份文档合并后，实际包含至少**七门生意**：

| # | 生意 | 客户 | 收入来源 | 获客方式 | 成败关键 |
|---|---|---|---|---|---|
| B1 | 商业知识内容 | 学习者 | 课程费／订阅 | 内容+SEO+社群 | 流量与完课转化 |
| B2 | 一对一生意咨询 | 有项目的个人 | 时费／项目费 | 转介绍与个人品牌 | 杨的时薪与口碑 |
| B3 | 批次制加速器 | 同期 6+ 人 | 批次费 | 需持续项目供给 | 同期人数密度 |
| B4 | 托管代执行 | 怕销售的人 | 服务费 | 效果案例 | 人工成本与合规 |
| B5 | 买方撮合市场 | 双边 | 抽佣 | 双边补贴 | 双边冷启动 |
| B6 | 结果数据基础设施 | 未定 | 未定 | 依赖 B2–B5 存量 | 样本量与可比性 |
| B7 | 微型孵化／分成 | 被投项目 | 分成／股权 | 项目筛选 | 资本回收与监管 |

**七组相互冲突**（这是三份文档从未做过的对撞）：

1. **B1 × B3**：课程经济学要求**更多学员、更低筛选**；加速器要求**更少学员、更严筛选**。同一团队不能同时优化两者，且 B1 因为更容易卖，会持续侵蚀 B3。
2. **B3 × B5**：加速器的学员按定义是**未验证的新手**；买方网络的存续依赖**供给质量**。把新手推给真实买方，会以最快速度烧掉买方信任。**"服务尚未成功的人"与"经营一个买方网络"是直接对立的。** 这是最硬的一组冲突，文档中只以"低质量供给是否伤害买方"一个疑问句出现，从未与核心用户假设对撞。
3. **B2/B4 × B6**：数据资产要求**杨退出交付**（否则样本不可比且不可扩）；早期现金流要求**杨深度介入**。越早跑通 B2，B6 越难成立。
4. **诚实停止 × 全部获客**：产品最有价值的诚实产出是"论证充分的停止"。但**转介绍和案例只能来自成功者**。一个高诚信的"劝退机"在结构上拥有最差的口碑经济学。文档 §12 把"及时停止减少的损失"列为层 4 指标，但没有回答：**这个结果如何转化为下一个客户？**
5. **低频 × CAC**：一个人一生启动"新商业项目"可能只有 1–3 次。无复购、无订阅理由（除非人为延长依赖，而合规文件 §4 已把订阅的利益冲突登记在案）。**LTV ≈ 一单**，CAC 必须极低，但见冲突 4，最便宜的获客渠道恰好被堵死。
6. **B7 × 合规**：给用户资金、收分成、结果付费，均触发合规文件 §4 要求的**中国适用法律书面边界备忘录 + 持牌法律人士复核**。这不是文案问题，是准入成本。
7. **B4 × 责任**：代发外联触发名单来源合法性（个人信息保护）、垃圾信息、平台规则、品牌归属与错误赔偿。LLM 地图 §10 已列出十条问题，**没有一条被回答**，但 B4 在 YC 文档 §6 的场景里已经被写成默认交付内容（"帮助形成并核验第一批目标名单"、"设定由谁发送"）。

**结论**：这不是一个产品的七个模块，是七门需要不同能力、不同获客、不同单位经济、且**至少四对直接对立**的生意。文档把它们并列保存是正确的研究动作；但并列保存本身**不解决**它们不能同时启动这一事实。

## 八、最可能遗漏的三个竞品／历史反例类别

以下均为 `I/H`，本轮**未检索、未核验**，仅作为 DR02 的候选检索方向提出。

### 类别 1｜中国境内的补贴型与机构型创业加速供给
三份文档的竞品集（生财有术、Starter Story、Side Hustle AI、GhostCoach、Audos、On Deck）**全部是市场化产品**，完全遗漏了中国的一大类供给：地方政府与园区的创业孵化服务、人社系统的创业培训与补贴、高校创业学院、以及各类众创空间的免费加速营。

**为什么这是最致命的遗漏**：如果"个人商业项目加速"在相当程度上存在**大规模免费或补贴供给**，那么付费意愿的天花板不由竞品定价决定，而由免费替代品的存在决定。LLM 地图和 YC 地图讨论了"被通用模型免费化"的风险，**从未讨论"被公共财政免费化"的风险**。在中国市场，后者可能是更硬的约束。

### 类别 2｜Cohort-Based Course（批次制课程）品类的整体兴衰
2020–2023 年间存在一个规模不小的品类自然实验：批次制在线课程与 cohort 型加速项目。这个品类的头部产品经历过明显的扩张与收缩。**它与 H-YC-02（批次机制可迁移）高度同位**——同样是筛选、同期、固定导师、高频反馈、外部里程碑，同样面向个人而非公司。

三份文档中 `On Deck` 出现了一次，但只作为"筛选与网络"的机制参照，**没有作为"批次制个人加速"这一品类的墓碑或收缩样本被检索**。这是 DR02 中最同位、信息增益最高的一格。

### 类别 3｜结果绑定收费（ISA／先学后付／保就业）的监管与失败样本
文档 §7 表格里 `Mocha／Prehired` 出现过一行，但**没有作为一个类别展开**。收入分成协议、"保offer"、"就业后付款"这类结构，在美国遭遇过监管与集体诉讼，在中国对应"先学后付"与保就业培训的投诉与监管。

这直接同位于 H-YC-06 之后可能出现的分成、担保、押金和微型孵化设计。合规文件 §4 已要求法律备忘录，**但深度研究执行计划的 DR01/DR02/DR03 中没有任何一项覆盖这一类墓碑**。这是合规文件与研究计划之间的一个空隙。

**补充（第四类，强度略低但同位度最高）**：一对一 business coach / 生意教练是一个成熟的活体行业，它正是"YC 去掉资本、品牌、网络后的剩余形态"。它的真实单价、获客方式（几乎全部依赖内容与转介绍）、留存和规模天花板是可公开观察的。三份文档把它列在替代品表的一行里，从未把它作为**主要对标**研究。它比 Audos 更同位，且材料更易得。

## 十一、单位经济失效路径

| 失效通道 | 机制 | 当前可算性 |
|---|---|---|
| 单客人工 | 摄入诊断 + 项目压缩 + 名单核验 + 报价审查 + 周复盘 + 交付检查 + 结项复盘。若代执行进入交付，再加名单与外联工时 | 无法计算（工时 `Ø`、价格 `Ø`）。**但可零成本自估**：见下节证据 3 |
| 获客 | 低频（一生 1–3 次）+ 不可承诺结果（合规）+ 案例稀缺（多数产出是"停止"）→ CAC 高而 LTV ≈ 1 单 | `Ø` |
| 低频决策 | 无自然复购。订阅化会触发合规文件 §4 登记的"延长依赖"利益冲突 | `H` |

## 十二、三条最便宜的裁决证据

### 证据 1｜合规剩余量测试
**做什么**：把加速器压成一页真实报价（一句话价值主张 + 交付清单 + 不交付清单 + 一个价格 + 退款规则），然后逐条对照 `compliance/禁止承诺与证据门槛.md` §1 与 §2，划掉所有不许说的话，看剩下的文字是什么。
**成本**：1–2 小时。**零外部接触、零支出、无需任何授权。**
**为什么最便宜且最能改变决定**：它同时测试 C-03、攻击 1，并且第一次把"抵抗通用 LLM"和"禁止承诺"两张表对撞。
**停止条件**：若剩余文本与"一个通用模型 + 一份公开商业课"能提供的承诺**无法区分**，则加速器形态在当前合规标准下**不具备独立可售性**。此时必须二选一：降低自我合规标准（并重新裁决责任），或放弃"独立售卖判断与验证"，转向"判断嵌在什么里面卖"（执行计划 §7 结果 B 的路径）。

### 证据 2｜最小批次规模与渠道量级对账
**做什么**：杨写下两个数字——（a）批次形态成立所需的最小同期人数；（b）当前可合法、非人情触达的同情境对象数量级。
**成本**：30 分钟。零接触。
**为什么关键**：它直接裁决 C-06。批次的最小可售单位是一个批次，这一点在三份文档中从未被计算过。
**停止条件**：若 (b) < (a)，**批次形态在第一阶段不可执行**，YC 类比中剩余的最后一项组织机制失效，形态自动退回一对一。同时 Batch 0 应并入 E001。

### 证据 3｜单客工时与最低价格反推
**做什么**：按第一阶段的最小交付（摄入 + 报价压缩 + 一次外部动作 + 一次复盘），估算杨的单客小时数上限，乘以杨可接受的最低时薪，得到最低价格；再把这个价格放回证据 1 的合规剩余文本中问：**有人会为这段话付这个价吗？**
**成本**：1 小时。零接触。
**为什么关键**：它把 C-13 从 `Ø` 提到 `I`，并第一次让"价格"与"允许说的话"发生接触。
**停止条件**：若最低价格显著高于同位免费／补贴供给（见第八节类别 1），或高于一对一 business coach 的市场区间，则**个人自费路径不成立**，必须转向机构付款或打包嵌入，且滩头人群随之改变。

**说明一条我认为真正的决定性证据，但当前不可执行**：一次真实报价投向一个非人情渠道，观察是否有人问价。这是唯一能把 C-02 从 `Ø` 移动的证据。它需要杨对**具体动作**的明确授权（联系真人、公开发布、报价），本报告不建议、也无权启动。以上三条证据的作用，是让这次报价在发生时**不至于因为文案不合规、价格无根据、形态选错而浪费掉这次机会**。
