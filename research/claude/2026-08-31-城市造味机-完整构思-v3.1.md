## 零、北极星，以及它解掉的三个分叉

**北极星：带动一座城市的经济活力与人流。**
不是"我们赚多少钱"，不是"我们捧红几个厨师"。这两者只有在服务北极星时才成立。

这一条定下来之后，此前三个悬而未决的取舍**自动有了答案**：

| 分叉 | 服务北极星的一侧 | 理由 |
|---|---|---|
| **高端 vs 低端** | **低端** | 免费、人人可参与、人人可拍——只有低门槛才能带动全城，高端小众从来带不动城市经济 |
| **名人 vs 素人** | **素人** | 名人是外来的、会走的；素人是本地的、留下的，而且他成名本身就是本地故事 |
| **造星 vs 造吃法** | **造吃法为主线** | 吃法留在本地、所有商户都能用、带动全城；厨师是你的资产但会走 |

**这不是我替你选的，是你的北极星推出来的。** 三个分叉一起倒向同一侧，说明北极星选得干净。

### 必须同时接受的代价

北极星定成"带动城市"，等于把这件事从**"我的生意"**改成**"我的服务业务"**。

天花板从"拥有一个 IP 帝国"降到"一家优秀的文旅内容运营服务商"。服务商现金流稳、轻资产、可复制、可持续，但不是能暴富的结构。

**这与你说的"不自己干"完全一致，所以我判断你是清醒的。但它必须被明确接受，而不是默认。**

### ⚠️ 与仓库规则的一处冲突，需你裁决

VentureLab 创造门要求登记"**我方可控制的差异**"和"**成功后我方保留的资产**"。

但本方案的北极星要求**扩散越广越好**——吃法被周边商户抄走，对城市是好事。这两条方向相反。

我的解法：**你控制的不是菜，是两样别人抄不走的东西**——
1. **持续产出新吃法的赛制**（下一道从哪来）
2. **原产地认证**（谁是发源地）

菜随便抄，机制在你手里。这与创造门可以兼容，但必须在假设账本里写明"控制层级 = 机制层，非产品层"，否则会与宪章的默认口径冲突。

|---|---|---|

| **侦侦日上 /《一饭封神》· ROTATION（Napa）** | 前者签黎子安等米其林/亚洲50最佳厨师做博主，2026 年已播第二季，明确在往线下体验走；后者每月请一位名厨（Martin Yan、Top Chef 冠军），有常驻行政总厨托底，与官方 DMO Visit Napa Valley 联合发布 | **顶部已被占满，且他们全在"借星"，没人做素人和吃法** |

## 二、核心机制：爆点的载体是吃法，不是人

### 2.1 证据

| 城市 | 真正的爆点 | 是什么 |
|---|---|---|
| 淄博 | 小饼卷肉加小葱 | **动作** |
| 天水 | 甘谷辣椒油泼 | **做法** |
| 哈尔滨 | 冻梨切盘、搓澡 | **动作** |
| 大唐不夜城 | 不倒翁小姐姐 | 人格（但后来各地都能复制这个角色） |

**四个里三个是动作。原因很硬：动作能被每一个游客复制和拍摄，人不能。**

你没法复制一个厨师，但你可以把冰块塞进西瓜然后拍下来。**城市美食现象的传播主体从来不是店主，是游客本人。**

### 2.2 这个修正顺手降掉两个最大风险

| 原风险 | 变化 |
|---|---|
| K2 素人造星可能根本不成立 | **不再是地基**。你不需要"能红的人" |
| K8 供给侧枯竭 | **大幅缓解**。从"手艺好+有表达欲+有故事的人"降到"愿意试新吃法的厨师"，供给宽得多 |

厨师从明星降级为**研发者兼表演者**。这是简化，不是降级。

### 2.3 可复制性是分发机制，不是漏洞

杨的原话是全场最反直觉也最对的一句：**"哪怕周边的人复制了，对当地来说也是带动。"**

商业直觉是防抄袭；城市经济逻辑正相反。淄博烧烤全国开店，反而强化了"正宗在淄博"。

**所以设计上要主动教人抄。** 公开配方、公开做法、鼓励模仿，同时把"发源地"和"下一道菜"锁在自己手里。

### 2.4 造味机的运行结构

```
输入：世界各地的新吃法／新形式  +  本地既有菜系与食材
   ↓
嫁接：由厨师试做，一周若干版本
   ↓
筛选：街面免费试吃投票，路人当场投票
   ↓
输出：每周一道新吃法 —— 命名、归属本地、拍成内容
   ↓
扩散：鼓励所有商户复制，越抄越强化原产地
   ↓
沉淀：赛制品牌 + 原产地认证 + 厨师关系（副产品）
```

### 2.5 两个新增风险

- **产出速率。** 前 20 个新吃法容易（世界各地现成的），第 30、40 个从哪来？这决定"不断有话题"是真是假。
- **老字号抵触。** 你动的是别人的招牌菜。火宫殿不会欢迎外来组织教它改臭豆腐。
  **→ 第一批只能找没有历史包袱的素人和新店。** 这与"开放麦"路线天然合流。

## 三、S1：样板房是"四件套"，不是一场节

### 3.0 对 v3 初稿的修正

v3 初稿主张"样板是一场节，不是一家店"。**这一条被杨推翻，我接受推翻。**

理由是我漏掉的：**节办完就散场，领导来了没东西可看。** 政府侧的决策高度依赖现场考察，"我办过一场节"是过去式的口头陈述，"我这有一家店，你随时来"是现在式的可核验事实。而且样板房必须**活着**——一个在亏损的样板店，本身就是坐在那里的反例。

### 3.1 样板房的四个组件，各有各的功能

缺一不可，但功能完全不同：

| 组件 | 对政府证明什么 | 对你自己是什么 |
|---|---|---|
| **① 店（常设）** | 我们能长期运营，不是来骗补贴的 | 现金流底盘 + **可随时接受考察的现场** |
| **② 赛制（每周固定）** | 机制可重复，不是一次性运气 | **核心资产** |
| **③ 节（每季或每半年）** | 这套东西放大到街面也成立 | 数据采集器 + 爆发窗口 |
| **④ 厨师账号矩阵** | **我们能带来声量** | 分发能力的凭证 |

**节不是店的替代品，是店的对外放大形式。** v3 初稿把二者对立起来了，是错的。

### 3.2 "活得可以"必须定义成"不失血"，不是"赚钱"

这个定义决定了样板房会不会自我摧毁。

如果达标线定成"要赚钱"，你会被迫做一系列伤害机制的妥协：稳定菜单、减少轮换、砍掉免费试吃、少拍摄多翻台。**最后你会得到一家还行的餐厅，和一个死掉的赛制。**

正确的达标线是三条，都不含利润：

1. **月度现金打平或接近打平**（不需要持续输血）
2. **有稳定复购客群**（证明不是靠猎奇的一次性流量）
3. **能持续开门**（不因厨师轮换而中断出品）

### 3.3 常驻主厨回到第一优先级

既然店必须常设且必须活着，**常驻主厨从"节庆形态可以绕开"变回"必须先解决的第一件事"**。

Napa 的 ROTATION 正是靠常驻行政总厨 Jeff Mosher 统领后厨、与每位客座协作、在空档期运行核心菜单，才让轮换制餐厅得以日常运营。

**人选画像修正（比 v2 更具体）：**
不要找"名厨"。要找**能把别人的构想落地成稳定出品的人**——类似综艺后厨的执行总厨、或连锁餐饮的研发主厨。

| | 名厨 | **执行/研发型主厨（要找的）** |
|---|---|---|
| 诉求 | 个人表达、署名 | 把东西做出来、做稳 |
| 对当配角 | 抗拒 | 本职就是配合 |
| 对每周换菜 | 抵触 | 日常工作 |
| 好找程度 | 难，且贵 | **相对好找** |

### 3.4 店的日常结构

| 时段 | 内容 | 作用 |
|---|---|---|
| 周三–周日 | 常驻主厨的核心菜单 + 当周入选新吃法 | **养活这家店**（不失血的来源） |
| 周一或周二晚 | **免费试吃投票夜**，路人可参与，当场揭晓下周上什么 | 仪式层、内容层、机制证明 |
| 每季／每半年 | 把投票夜放大到街面，办 1–2 周的节 | 爆发、数据、给政府看可放大性 |

**淡日做投票夜**是这里成本效率最高的一处：周一周二本来就空着，用它做机制运转，边际成本几乎只有食材。

### 3.5 ⚠️ 成本量级在这里跳了一档

必须讲清楚，因为这是整个讨论里第一次跳档：

| | v3 初稿（只办节） | **本节（四件套）** |
|---|---|---|
| 时间 | 5 周 | **至少 12 个月**（"活得可以"需要时间证明） |
| 承诺 | 无租约、无证照、无雇佣 | 租约 + 证照 + 装修 + **常驻主厨等长期雇佣** |
| 量级 | 几万元 | **六位数中段到七位数低段** |
| 需要的人 | 一个组织者 | **一个每天在店里的全职经营者** |

**杨已明确"不自己干"。因此有两个问题必须先答，否则本节无法执行：**
1. **谁出这笔钱？**
2. **谁是那个每天在店里的人？**

### 3.6 顺序：测试与选址并行，不是二选一

我让出"节替代店"这一条，但保留一条更弱的坚持：

**第九节那个五周实验不是店的替代品，是店的前置，且可以与选址、找主厨并行。**

它只花几万元和五周，不构成路径延迟；但它决定的是**店里那个赛制该怎么设计**。不测就开店，等于带着一个没验证过的机制去签一年租约。

### 3.3 "不断有话题"的可证伪口径

这句话不写死就是一句漂亮话。可数的版本：

> **连续 12 周，每周至少产出 1 道有名字的新吃法 + 1 个可传播的赛果。**

赛制的本质就是**定期生产新闻**。做不到每周一条，核心主张即为假。

### 3.4 城市选择判据（仍未定，卡着三件事）

1. 本地菜系身份鲜明，**外地人一眼能识别**（长沙符合）
2. 本地没有强势餐饮内容机构
3. 地方政府对文旅饥渴，有可谈的对口部门
4. 租金人工低

> **修正说明：** v2 曾写"美食是普世的，不属于任何地方"——**这句是错的，已撤回。**
> 正确说法是：**"做美食"这个类目不属于任何地方，具体的菜属于。** 长沙的臭豆腐、口味虾、糖油粑粑、剁椒鱼头，就是长沙的"唐"。
> 所以选址不是找"美食城市"，是找**菜系籍贯鲜明**的城市。

## 四、厨师账号矩阵：功能是凭证，不是收入

### 4.1 对 v3 初稿的第二处修正

v3 初稿把 MCN 降级为"副产品"，理由是收入不稳（日日煮广告收入三年蒸发 92%）。

**这个理由本身用错了地方。** 在本模型里，厨师账号矩阵的功能**不是赚钱，是证明分发能力**。

政府买的是客流和声量。你说"我们能带来声量"，对方会问凭什么。这时候能拿出来的只有一样东西：

> 我们有 X 个厨师账号，合计 Y 万粉丝，上月总播放量 Z，其中本地相关内容占比 W%。

**这是可核验的凭证，也是四件套里唯一能量化"声量能力"的部分。** 没有它，你的提案在"你凭什么带来人流"这一问上是空的。

### 4.2 因此它的 KPI 与商业 MCN 完全不同

| | 商业 MCN | **本模型的账号矩阵** |
|---|---|---|
| 目标 | 单个账号变现能力最大化 | **总声量 + 本地关联度** |
| 成功标准 | 出头部 | **矩阵整体可展示、可持续更新** |
| 厨师红了走人 | 重大损失 | 影响有限——**"从我们这儿出去的"本身就是凭证** |
| 收入预期 | 主要收入线 | **不作规划基础**，有就是白赚 |

**日日煮的教训仍然成立，但适用范围要收窄：不要把内容广告当主收入线。** 这不妨碍把账号矩阵当作能力证明来经营。

### 4.3 合约与人的处理

- 从第一天守住的只有**拍摄授权与肖像使用**，其余从宽——零战绩的平台没有开条件的资格
- 有人红了就签，签不到就算了
- 分手条款预先写好，把离开做成可预期的事，而不是事故
- **不把任何硬 KPI 押在"捧出头部"上**

### 4.4 收入结构（先成立、后放大）

1. **政府／文旅采购的运营服务费**（最先成立，最稳）
2. **店的日常营业与节的门票**（不失血的来源）
3. **品牌赞助与冠名**（节比账号好卖）
4. 复制输出的服务费
5. 内容与经纪（副产品，不作规划基础）

## 五、S3：复制路径与资金结构

### 5.1 不夜城的四个死因，三条你占优

行业分析（靳书芳，《现代商业》）把症结归为四点：

| 死因 | 本方案 | 判定 |
|---|---|---|
| ① 公共产品属性，企业承担外溢成本无补偿 | 同样存在 | ⚠️ **靠资金结构解决**，见 5.2 |
| ② 免门票导致缺稳定基础收入 | 有采购服务费 + 场内收费 + 赞助 | ✅ 优于不夜城 |
| ③ 常态化演艺持续抬高成本 | **我们的"演员"是厨师，厨师演出的产物是能卖钱的饭** | ✅ **最强的一条** |
| ④ 营收单一依赖商业分成，客流一跌即恶性循环 | 服务费不随客流同步崩塌 | ✅ 抗跌性更好 |

> **提案核心句：**
> 不夜城的演艺是纯成本——灯光要维护、演员要发工资，每月三百万烧掉，不产生任何直接收入。
> **我们的"演艺"自带营收：厨师在台上做的菜，当场就卖出去了。**
> 这不是文旅项目的优化，是把成本项换成了收入项。

**同时：提案里不能出现"不夜城"三个字，且必须主动说清"我们不是不夜城"。**

### 5.2 资金结构：走采购，不走投资

杨已指出核心矛盾：**大唐不夜城运营方不怎么赚钱、应收难收，但城市是实打实增长的；而国资一旦亏损，领导要担责任。**

这正是死因①。国有资产保值增值考核意味着"我们一起亏、城市赚了"这个方案**在国资体系里签不动**。

**解法是换资金科目，不是换说服力。**

| | 走投资 | **走采购（采用）** |
|---|---|---|
| 逻辑 | 要回本 | 花预算 |
| 亏损 | 国有资产损失，追责 | 不存在"亏"，只有 KPI 达没达成 |
| 频率 | 一次性决策，极难 | **每年都在花** |

淄博那 2000 余场活动的钱，来自文旅宣传预算，不是投资。**你不是去要一笔投资，你是去替他们花已经批下来的宣传费、节庆费、招商推广费，而且效果可测。**

若必须国资入股：让文旅集团**以场地和免租作价入股**，现金投入压到最小，敞口小则追责风险小。

### 5.3 合作结构：委托运营，不做股权合资

| 谁 | 出什么 | 拿什么 |
|---|---|---|
| 政府／文旅方 | 场地、基建、公共部分投入、政策资源 | 资产、税收、就业、城市声量 |
| 你 | 赛制、吃法库、内容团队、运营 SOP | 服务费（保底）+ 超额分成 + 内容与经纪收入自留 |

理由：你贡献的是无形资产，**国资体系对无形资产作价出资极为审慎**，很可能不认，最后要你拿现金进来——与"不自己干、轻资产"直接冲突。

> **第一份提案里就要写死：街区是他们的，赛制和吃法库是我们的。**

### 5.4 "小麻雀"的验收口径：按政府的数字

政府不关心你赚不赚钱。他们看三个数：

| 指标 | 口径 |
|---|---|
| 客流 | 到访人次，**尤其外地游客占比** |
| 停留与外溢 | 平均停留时长、周边商户二次消费变化 |
| 声量 | 可截图的传播数据、上过的榜单与媒体 |

**含义（对你是好消息）：小麻雀不需要盈利。** 它要证明的是机制能持续造话题和客流，不是单店经济成立。这实质降低了 S1 门槛。

## 九、最便宜的反证实验

**不需要开店，也不需要办完整的节。** 打 K1 和 K2 两条地基：

```
第 1–2 周｜供给与产出速率测试
  招募愿意试新吃法的本地厨师／摊主
  两周内产出 6 道"本地菜 × 外来形式"的嫁接版本
  判错：凑不出 6 道，或全部难以下咽 → K2 成立

第 3–5 周｜仪式层测试
  借一处现成的夜市／商圈空地，连办 3 场周末街面试吃投票
  免费或一口价几元，路人当场投票，当晚揭晓
  记录：到场人次、投票参与率、自发拍摄条数、二次到场率
  判错：3 场中到场人数持续走低，或几乎无人自发拍摄 → K1 成立
```

- **量级**：几万元、5 周、无租约、无证照、无雇佣
- **产出**：一份可直接拿给文旅部门看的"三张数据表"雏形
- **这个实验之前的所有设计（包括本文件）都是纸面推演。**

## 十、分支纪律与两个 A/B

杨的裁决："决定不了的方向保留成两个分支，做 A/B 测试。"
**采纳，但加一条纪律：**

> **能在同一次实验里并行跑的，才做 A/B；必须分别投入才能跑的，不是分支，是必须选一个的岔路。**

按这条纪律筛下来：

### 已被北极星解掉、不再是分支的（三个）

高端/低端、名人/素人、造星/造吃法 —— 见第零节。不保留分支。

### 不是分支、是先后关系的（一个）

**节 vs 店。** 这两个不是并列，是先后：节是店的前置。先办节验证机制，节跑通了店才有意义（店是节的常设化）。而且**节可以证伪店**——节都没人来，店必死。

### 真正值得做的两个 A/B（都能在同一场节里并行）

| | **A/B 1：投票对象** | **A/B 2：吃法来源** |
|---|---|---|
| A | 票投给**一道吃法** | **外来嫁接**（西瓜挖洞塞冰块一类） |
| B | 票投给**一个厨师** | **本地深挖**（老吃法换新形式） |
| 怎么跑 | 一晚投吃法，一晚投人 | 同场并列上，各占一半 |
| 看什么 | 到场人次、投票参与率、自发拍摄条数 | 同上 + 本地商户反应 |
| 增量成本 | ≈ 0 | ≈ 0 |

A/B 1 尤其重要：北极星指向"投吃法"，但**如果实测发现观众明显更愿意为"人"投票，那说明故事性的拉力强过新奇感**，整套设计要往回调。这是唯一一个可能推翻第零节结论的实验。
