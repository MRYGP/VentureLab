## 一、三条并行线

### A｜杨：真实客户与进入线

1. 在仓库外完成 `D:\VentureLab-private\通道清单.local.md`；真人姓名、资金和私人关系不得进入公共仓。
2. 按真实日历容量安排首批对话，不为凑数降低对象质量。
3. 对话先问事实，后测方案：
   - 最近实际发生的高成本问题；
   - 目前如何解决、钱从哪里出、谁签字；
   - 对方是否愿承担数据、时间、内部协调、审批或现金成本；
   - 方案提出后，第一单可能按什么计价。
4. 只向公共仓交付脱敏行为账本，不提交身份映射。
5. 记录第一次真实拒绝后的追问、调整与下一动作，用于更新私人创始人画像中的待验假设。
6. KAIROS 继续按 SK 活看板推进，不因 VentureLab 研究暂停；通过 KAIROS 招募、制作、创始客户验证出现的真人，若完成具体任务，可作为进入侧行为进入同一账本。KAIROS 的项目状态仍只以 SK / SKZJ 的现行文件为准，VentureLab 不替它改状态。
7. SK 公众号是进入线的公开获客渠道，不是新增研究线。它可以吸引正在创业、有想法、有资源、有行业经验、有技术能力或其他特殊能力的人，但不能因自我介绍、点赞或泛泛合作意向获得进入加分。
8. 跨境操盘者只是候选人类别之一，不单开“跨境第二线”。所有候选人都经过同一条路径：经历核验 → 具体任务 → 可核材料或真实引荐 → 下一动作。对 `D:\chinafood` 的有依据否定可以成为有效行为证据，不要求候选人支持既有方向。

行为账本至少包含：对象类别、最近问题、当前解法/支出、预算方、签字人、愿承担的成本、对方的犹豫/否定/拒绝理由、下一动作。

**完成定义**：至少发生一条真实外部对话并进入行为账本。行为账本为零行时，不开启会合窗口，本周只处理路线 A；两份研究报告不能代替客户事实。

**交付**：脱敏客户行为账本 + 进入能力汇总 + 下一轮可约对象类别 + 本轮没有取得的事实及实际覆盖范围。

### B｜Codex：Yoodli 本体与同位生死线

1. 核验 Yoodli 当前产品、个人与企业定价、真实付款方、预算归属、销售与合作渠道、企业采用和留存证据。
2. 区分用户价值、留存机制、企业切换成本和护城河。
3. 核验公司自报指标的证据边界，不把客户 Logo、融资和自述 ROI 当作独立商业证明。
4. 研究少量直接活体对标，以及同一具体工作、同类付款方或采购链中的失败、终止、并入和免费化反例。
5. 核查中国已有同类供给、在位者入口和平台内置风险。
6. 对 Toastmasters 合作终止补做前后对照：观察到期前后 Yoodli 的定价、招聘节奏、产品/内容发布频率和企业案例发布是否变化；无法取得的维度明确记为 `Ø`。
7. 中国范围只负责演讲、沟通和销售话术陪练这一具体工作，不扩到监督、认证和其他经营结果工作。
8. 按现行执行计划的时间盒和样本上限停止，不为补数强塞邻近样本。

**交付位置**：`research/codex/`  
**交付**：独立报告 + 来源映射 + 最可能错误的三条判断 + 未找到事项与检索范围。

### C｜Claude：邻近结构与独立反例线

1. 第一轮不读取 Codex 新报告，不重复制作 Yoodli 官网摘要。
2. 寻找共享核心机制、但处于不同具体工作中的产品：把专家方法变成练习、反馈、监督、认证或经营结果。
3. 优先使用与 Codex 不同的来源路径：企业采购、行业协会与展会、垂直软件市场、中国招投标、停运公告、收购后退役和平台免费内置。
4. 对承担结论的活体检索同位失败、终止、并入与免费化反例；这里的“同位”相对于 Claude 找到的具体活体及其工作/付款链，不是相对于 Yoodli；找不到就保留 `Ø`。
5. 中国范围只研究演讲/沟通/销售话术陪练以外的具体工作，包括监督、认证和经营结果类供给，避免与 Codex 重复。
6. 不提出中国创业方案，不做最终排序，不修改仓库。

**交付位置**：原始报告由杨或 Codex 保存至 `research/claude/`  
**工作上限**：筛选候选样本不超过20个，深卡不超过8张；本轮单次会话完成，不跨轮追加；任一上限先到即停，不足8张不补数。以上是工作量上限，不是市场阈值。  
**交付**：独立报告 + 来源映射 + 最可能错误的三条判断 + 未找到事项与实际检索范围。

## 二、会合条件

三条线至少各返回一种新证据后才会合：

- 杨：真实问题、预算、签字链或愿承担成本的行为；
- Codex：Yoodli 付款/分发/留存边界及至少一条终止或失败证据；
- Claude：独立邻近结构或反例及其原始来源。

任一条线没有结果，可以明确交付“未取得”，不得用推断补空格。

**硬前置**：路线 A 的行为账本为零行时，不开启会合窗口；路线 B/C 可以归档，但不进入联合讨论。

## 三、第一次会合只做什么

1. 对三方来源去重；相同来源只计一次。
2. 建立共同事实包，分开 `F-M`、`F-P`、`I`、`H`、`Ø`。
3. 提取少量可迁移机制和短假设。
4. 标出哪些假设已有现实对象可以继续问，哪些仍只有桌面材料。
5. 形成给 PB 与 SK 的同一份事实输入包。输入包只含样本账本、原始来源、证据等级、事实陈述和空格清单，不含 Codex/Claude 的机制结论、排序或建议。

第一次会合不做创业方向前三，不把 Yoodli 自动升级为候选，不修改研究规则。

## 四、PB 与 SK 的第二阶段分工

共同事实包完成后再并行交接：

- **PB**：审查神圣假设、过去尝试者、生死边界、真实死因与今天的结构变化；
- **SK**：审查付款方、预算迁移、活体生存机制、获客、公司天花板与杨的进入能力；
- **联合窗口**：保留共识、冲突和空格，只决定下一条最便宜的行为证据。
