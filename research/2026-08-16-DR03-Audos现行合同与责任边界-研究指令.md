# DR03｜Audos现行合同与责任边界研究指令

> 日期：2026-08-16
>
> 状态：指令已建立，研究未启动
>
> 优先级：3，仅在DR01／DR02收口后有余量时执行
>
> 目标：从现行原始文件核清Audos各层产品、费用、权利和失败责任

## 一、核心问题

Audos公开出现过多种产品名、资金口径和分成说法，但现有材料可能混合了不同时间、项目层级和发布页。本研究只回答：

1. 当前公开存在的产品／项目层级分别是什么？
2. 谁与谁签约，谁付款或承担广告、人工、技术和资金成本？
3. 收入分成、royalty、订阅、资助、额度和资金池分别属于哪一层、哪个时间？
4. IP、数据、终止、退款、回收、独占、宣传授权和争议如何约定？
5. 项目失败、无收入、广告亏损、侵权或客户争议由谁承担？
6. 哪些环节由AI完成，哪些依赖人工、广告平台、导师、社群、机构关系或资本？

Mate、Otto、Publishing、EiR、Summer Camp等名称只作为待核线索；未在当前原文出现时不得写成现行层级。

## 二、事前待验命题

| 编号 | 命题 | 初始等级 |
|---|---|---|
| A1 | Audos普通用户与重点项目适用不同合同、资金和分成层级 | `H` |
| A2 | 平台对广告、人工和资金的承担有明确上限或附加条件 | `H/Ø` |
| A3 | 项目无收入或退出时，仍可能存在IP、数据、费用或宣传义务 | `H/Ø` |
| A4 | 完整交付依赖显著人工、分发和资本，不是单纯AI诊断 | `I/H` |
| A5 | 公开合同不足以计算平台单位经济和项目成功率 | `H` |

执行者检索前记录：预期能找到哪些文档、哪项最可能仍为`Ø`、什么证据会推翻A4。

## 三、时间与层级分账

每个数字和条款都必须带两个标签：

- **时间**：首次发布日期、最后更新日期、访问日期；
- **层级**：普通入口、特定计划、竞赛／夏令营、重点项目、投资／EiR或其他。

不同时间或层级的50美元、500—5000美元、25000美元／分成、50000美元资金池、最高100000美元等口径不得相加、替代或用于同一单位经济推算。上述数字目前只作为待核线索。

## 四、优先原始材料

按顺序寻找：

1. 现行Terms、Program Terms、Privacy、Revenue Share／Royalty或参与协议；
2. 官方FAQ、定价、项目说明和申请条款；
3. 公开合同附件、支付／广告额度说明；
4. 收购或项目调整正式公告；
5. 创始人／团队对合同和交付的明确说明；
6. 用户一手公开材料；
7. 可信媒体，仅用于补背景；
8. Product Hunt、评论和聚合页只作线索。

公司条款是`F-P`，可证明规则和权利主张；除非有真实执行材料，不能证明实际付款、人工投入、用户收入、淘汰率或平台利润。

若只能取得通用Terms、Privacy或网站使用条款，不能据此判断特定Program、收入分成、资金计划或项目层责任“较轻”；这些项目层责任继续标`Ø`。

## 五、合同提取表

| 字段 | 必填内容 |
|---|---|
| 文档名称／版本 | 完整标题、URL、更新时间、访问日期 |
| 适用主体 | 平台法律主体、用户／项目主体 |
| 适用层级 | 哪类计划或用户 |
| 费用／分成 | 基数、比例、期限、触发和上限 |
| 广告与第三方成本 | 谁预付、谁回收、超额谁承担 |
| 资金／额度 | 现金、代金券、广告额度或竞赛奖金 |
| IP与内容 | 所有权、许可、宣传和退出后的权利 |
| 数据权限 | 收集、使用、共享、删除和模型相关条款 |
| 人工支持 | 承诺、限制和是否收费 |
| 退出／终止 | 单方终止、结清、持续义务 |
| 失败责任 | 无收入、亏损、侵权、客户争议的承担 |
| 争议与法律 | 适用法、仲裁／法院、责任限制 |
| 原文状态 | 已核原文／摘要／无法访问 |

短引文只保留定位所需片段，不长篇复制条款。

## 六、交付结构分解

对每一层分别标记：

- AI诊断／生成；
- 人工审核、运营或策略；
- 广告与客户获取；
- 社群、导师和活动；
- 资金、额度或投资；
- 外部平台和机构关系；
- 用户本人必须完成的动作。

只有公开条款或流程能证明“提供什么”；是否实际交付、成本多少和效果如何仍需行为证据。

## 七、工作上限与停止条件

- 定向检索不超过8次；
- 深读原始文档不超过5份；
- 只得到新闻稿、融资报道或官方营销页时停止；
- robots、登录或地区限制阻止原文时标`Ø`，不得绕过；
- 无法取得合同不得用评论重建合同；
- 缺人工分钟、广告成本、项目收入分布时，不进行单位经济估算；
- 不扩展为Audos公司史、创始人传记或全量用户案例扫描。

## 九、禁止结论

- 把公司条款当成用户真实结果；
- 把最高资助额当作普通用户可得资金；
- 把广告额度当作现金投入；
- 把收入分成比例当作平台真实收入；
- 把AI入口外推为端到端无人交付；
- 把无法访问的合同根据评论或旧报道补写；
- 因Audos存在就推断中国市场、EarnPath需求或杨的进入能力成立。
