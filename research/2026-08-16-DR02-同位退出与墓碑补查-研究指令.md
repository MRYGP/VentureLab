# DR02｜同位退出与墓碑补查研究指令

> 日期：2026-08-16
>
> 状态：指令已建立，研究未启动
>
> 优先级：2
>
> 目标：寻找足够同位的退出、停止、免费化和失败边界，不把“没找到”当机会

## 一、核心问题

在“AI帮助个人选择或验证副业／创业／个人变现路线，并可能持续跟进”这项具体工作中：

1. 哪些独立产品或服务已经停止、退役、免费化、转型、被收购或被并入？
2. 哪些只是品牌、产品或更新停止，主体仍存续？
3. 能否取得退出原因，而不是仅观察到结果？
4. 同位样本缺失是品类年轻、命名分散、供给被通用模型免费化，还是公开资料不足？

本研究不以“必须找到墓碑”为成功标准。可靠的`Ø`优于强塞Mocha、Prehired或其他邻近死者。

## 二、事前待验命题

| 编号 | 命题 | 初始等级 |
|---|---|---|
| T1 | 过去三年存在至少一个足够同位的独立产品退出或转型 | `H/Ø` |
| T2 | 部分低价路线生成器因通用模型替代、低留存或获客困难停止 | `H/Ø` |
| T3 | 同位产品的公开失败原因可以从创始人、公司或交易材料核验 | `H/Ø` |
| T4 | 没有公开墓碑主要反映检索与命名困难，而非品类无失败 | `H` |

执行者必须先写预测，并列出一种会推翻“该品类有结构性死亡机制”的结果。

## 三、同位标准

只有同时满足多数条件，才列为同位候选：

- 面向个人而非企业内部经营团队；
- 核心工作包含选方向、排除方向或设计市场验证；
- AI承担关键诊断／建议环节，而非只有文案生成；
- 产品宣称或实际提供持续跟进、行动计划或状态记忆中的至少一项；
- 能区分为独立产品、功能或人工服务。

只做课程、社群、代运营、求职培训、通用商业教练或结果融资的，默认邻近，除非有证据证明任务重叠。

## 四、必须区分的退出类型

| 类型 | 定义 | 可接受证据 |
|---|---|---|
| 主体破产／注销 | 法律主体终止或进入正式程序 | 法院、注册、监管、正式公告 |
| 产品退役 | 公司仍在但该产品明确停止 | 官方退役公告、商店下架记录 |
| 服务停止 | 服务不再接单或交付 | 官方说明、可核时间线 |
| 品牌消失 | 品牌页面、账号和渠道停止 | 只能描述现象，不能自动写死因 |
| 被收购 | 所有权交易发生 | 正式交易材料 |
| 被并入 | 独立产品消失但能力进入其他产品 | 收购方／原公司公告和产品记录 |
| 免费化 | 原收费功能成为免费或平台内置 | 定价历史、发布说明、条款 |
| 转型 | 任务、用户或商业模式发生实质变化 | 前后产品、定价和创始人说明 |

“网站打不开”“长期没新闻”“搜索不到”只能触发补查，不能单独证明死亡。

## 五、检索路线

1. 现有低价AI路线生成器与窄域教练样本逐个检查当前状态；
2. App Store／产品发布页／官方更新日志查下架和最后更新；
3. 创始人公开复盘、转职或公司转型说明；
4. 收购、退役、并入和定价历史；
5. 投资方组合变化只作线索，不单独承重；
6. 监管、退款潮和投诉只在能与具体主体及时间线对应时使用。

静默退出至少需要两个时间锚点和两个不同类型的材料；即便确认退出，没有原始说明也不得推断死因。

## 六、墓碑记录模板

| 字段 | 必填内容 |
|---|---|
| 主体／产品／服务／品牌 | 分开登记 |
| 具体任务与用户 | 用一句话说明 |
| 同位等级 | 同位／邻近及理由 |
| 状态类型 | 八类之一 |
| 关键时间线 | 上线、收费、最后更新、退出／转型 |
| 付款证据 | 实付、收入、挂牌价或`Ø` |
| 状态证据 | 原始来源与日期 |
| 原因证据 | 官方、创始人、法院、媒体或`Ø` |
| 能证明 | 最窄事实 |
| 不能证明 | 不得外推的死因或品类规律 |
| 反证条件 | 什么材料会推翻当前分类 |

## 七、工作上限与停止条件

- 候选不超过12个；
- 深卡不超过4张；
- 定向检索不超过12次，原文抓取不超过5份；
- 达到上限仍无同位墓碑，结论为“本轮已检索未找到”，不是“没有竞品死亡”；
- 只找到邻近失败时单列，不填入同位分母；
- 无原因原文时可以确认状态，不得确认死因；
- 不因某产品停止更新就递归搜索其所有创始人和投资方历史。

## 九、禁止结论

- “没找到同位墓碑，所以市场空白／机会巨大”；
- “产品下线，所以需求不存在”；
- “主体仍在，所以该产品成功”；
- “被收购，所以商业模式成立”；
- “投诉集中，所以真实死因已知”；
- 把融资失败、低增长、创始人转职和产品无效自动画等号。
