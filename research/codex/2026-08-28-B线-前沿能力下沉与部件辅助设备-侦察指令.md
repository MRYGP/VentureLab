# B 线｜前沿能力下沉与部件／辅助设备进入侦察指令

> 版本：v0.1  
> 日期：2026-08-28  
> 首个线索入口：`inbox/2/3.md`  
> 性质：前沿能力与上下游进入方式的侦察指令；不是军工研究、技术投资清单、采购授权、产品候选池或 TradeLab 实验  
> 当前状态：指令已建立，尚未运行  
> 目标：面对我方暂时做不起的前沿整机，不只问“能不能复制整机”，还要拆出可民用迁移的能力、模块、非关键零件、附件、测试维护工具和应用层产品，判断哪一层既有真实买方又可能由我方控制

## 一、先把杨的意思说清楚

本指令处理两条不同路线：

1. **能力下沉／军转民或工业转消费**：某种原本昂贵、专用、受训练人员使用的能力，因为成本、尺寸、功耗、材料、算法、制造或供应链变化，开始进入普通企业或消费者场景。
2. **生态配套／卖铲子**：不做最难的核心整机，转而提供它规模化后必需的部件、接口、固定、供电、散热、防护、校准、测试、维护、收纳、培训或工作流工具。

这两条路线都不自动更容易。尤其“给前沿公司做零件”可能比做普通消费品更难，因为关键零件常要求更高公差、认证、追溯、保密、稳定供货、客户验证和更长销售周期。

本轮优先寻找的是：**非武器、非攻击、非敏感监控用途下，已有明确民用任务与买方的能力迁移或非关键配套。**

## 二、`inbox/2/3.md` 的证据边界

该文件是口播式案例线索集合，混合了：

- 前沿硬件与尚未交付的众筹产品；
- 普通消费品、宠物品、文创和收藏品；
- 公司／创作者自述、平台支持金额和营销解释；
- 可能存在的产品名、金额、技术参数和公司名转写错误。

因此它只能作为 `Agent／二手口播线索`，不能直接成为 `F-M` 或高负重 `F-P`。执行时必须先恢复每个对象的准确产品名、主体、原始页面和当前状态；无法恢复则淘汰，不根据口播补写事实。

## 三、本轮四句

1. 本轮只从 `inbox/2/3.md` 选 5 个具体产品，覆盖不同的技术进入层，不扫描整个军工、航天或前沿科技产业。
2. 产品被选择过的信号必须回到原始众筹、零售、采购、部署、合同或客户材料；支持金额和演示只证明平台支持或技术主张。
3. 本轮信息将改变：某项能力应该继续看整机，还是转看模块、非关键零件、附件／辅助设备，或直接关闭。
4. 完成后只向杨提交最多 2 个值得定向研究的对象；没有合格对象时输出“本入口暂不产生下一步”。

## 四、首批五个观察位

第一轮从 `3.md` 中优先恢复并核验以下五类对象，每类最多一个：

| 观察位 | 典型线索 | 要学习什么 |
| --- | --- | --- |
| 主设备补缺口 | Magic Screen、CometIQ 一类 | 不重造电脑／手机，只补主设备长期缺失的能力 |
| 旧设备改造模块 | Ciclora 一类 | 用可拆模块让旧设备获得新能力，同时保留原体验 |
| 前沿核心整机 | URXR1、Tiny AI PocketLab 一类 | 明确为什么整机离我方太远，能否拆出非核心配套 |
| 技术隐藏于消费表达 | Birdie、Stack Chan 一类 | 技术退到后台，情绪、动作或参与感成为购买入口 |
| 开放平台／开发模块 | M5Stack、开源硬件一类 | 谁为模块、扩展件、外壳、接口和开发辅助付费 |

以上名称只作待核线索，不预设存在、拼写正确、已交付或值得研究。若同一对象身份无法恢复，换成文件中同观察位的另一个对象；累计尝试不超过 10 个线索。

## 五、每个对象的第一层：事实恢复

固定核验：

1. 准确产品名、公司／团队和原始 URL；
2. 产品当前状态：概念、工程样机、众筹中、待交付、已交付、零售、停产、并入或失败；
3. 精确用户、付款者、原任务和当前替代；
4. 用户行为信号是什么，属于平台支持、已交付购买、零售、企业采购还是部署；
5. 技术主张来自谁，是否有第三方实测或客户材料；
6. 关键参数、价格和时间点是否已核原文；
7. 哪些口播因无法回源必须删除或降为 `Ø`。

只看到众筹页面时，不得写“已经完成市场验证”；只看到媒体或博主时，不得写“已经规模采用”。

## 六、第二层：把整机拆成能力栈

每个产品固定拆为：

```text
用户结果
→ 应用／交互层
→ 系统集成与控制
→ 核心技术模块
→ 通用模块与标准件
→ 定制结构件与材料
→ 供电／散热／连接／固定／防护
→ 测试／校准／维修／升级工具
→ 包装／收纳／运输／培训／售后
```

每一层分别填写：

- 谁设计、谁制造、谁承担责任；
- 是否能从公开材料确认外购或第三方供应；
- 是否存在独立采购者，而不只是整机企业内部自制；
- 当前价格、订单、供应商、认证和替换条件能核到什么；
- 我方可控制的是规格、设计、模具、流程、品牌、内容、客户关系还是 `Ø`；
- 单一供方依赖和迁移条件；
- 该层失败会不会直接造成安全、隐私、医疗、交通或其他高责任后果。

## 七、四条进入路线必须分账

### 路线 A：民用成品

将原能力用于明确的民用人群、新场景或新任务。必须说明原能力为什么仍承重，以及为价格、形态、信任、渠道、动作和责任做了什么改变。

### 路线 B：能力模块

例如传感、显示、通信、计算、执行、材料或控制模块。只有出现独立采购者、标准接口或多个下游客户时才值得继续；“整机里有这个模块”不证明外部市场存在。

### 路线 C：非关键零件／结构件

例如外壳、连接件、支架、线束、密封、散热、收纳或耗材。必须核验公差、材料、认证、追溯、MOQ、质检、知识产权和客户验证；不能把中国有供应链写成我方能拿到订单。

### 路线 D：辅助设备与工作流

例如安装、校准、测试、维修、防护、充电、运输、清洁、升级、训练、模拟或数据整理工具。优先寻找：核心设备越普及，配套任务越重复，而且设备厂商没有以可接受方式解决的部分。

四条路线可以全部关闭。不得为了产生机会而强行保留一个。

## 八、“军转民／专用转民用”核验纪律

只有原始官方材料、可靠历史资料、专利转让／许可、政府技术转移项目或公司明确技术谱系可以承担“军转民”“航天转民用”“实验室转消费”等来源判断。

- 军用外观、战术营销或创始人履历不能证明技术来自军方；
- 专利存在不能证明技术成熟、可制造或已获许可；
- 军方／航天采购不能证明民用价格可接受；
- 民用场景需求成立不能证明关键技术、出口、数据和最终用途合规；
- 不研究武器化、攻击、规避监管、敏感监控或受限用途；
- 涉及出口管制、军民两用、无线电、航空、医疗、交通、未成年人或隐私时，只用当前官方来源承重，并在不确定时停止，不提供规避路径。

## 九、进入侧行为证据

“可以给他们做零件／辅助设备”首先是 `H`。至少出现以下一项，才形成进入侧证据：

- 整机厂公开供应商招募、采购规格、认证流程或合作接口；
- 多家整机使用同一标准模块或附件接口；
- 独立配套厂已经向多个客户交付；
- 客户公开反复购买、替换、维护或抱怨同一配套任务；
- 真实合作方愿意提供样品需求、规格书、测试标准或小单；
- 杨已有可触达的供应链、工程师、渠道或客户能承担具体任务。

招聘画像、供应商目录、1688 页面、能力宣传和“深圳能做”只能提供线索，不能证明订单。

## 十、固定雷达卡

| 字段 | 要求 |
| --- | --- |
| 产品与状态 | 准确对象、主体、日期、原始页面、交付／零售状态 |
| 用户结果 | 谁使用、谁付款、为什么选择 |
| 选择证据 | 支持、成交、采购、部署、复购、退出或 `Ø` |
| 能力核 | 真正被购买的技术能力，不抄功能清单 |
| 原来做不到什么 | 成本、尺寸、功耗、材料、精度、制造或组织约束 |
| 现在变化了什么 | 哪个参数变化使产品化成为可能；来源和反证 |
| 能力栈 | 核心、通用模块、零件、辅助设备、服务逐层分解 |
| 四路线结论 | A 成品／B 模块／C 零件／D 辅助，分别保留、关闭或 `Ø` |
| 我方距离 | 需要的技术、现金、时间、认证、关系、供应链和责任 |
| 最便宜信息 | 一条会改变保留／关闭判断的信息，不直接询价或联系 |
| 合规边界 | 当前已知、未知和停止项 |
| 反证条件 | 什么事实会证明该进入层只是想象 |

不做跨量纲总分，不按“技术前沿程度”排序。

## 十一、停止线

任一对象满足以下条件时，关闭对应路线：

1. 产品仅有演示或众筹叙事，关键能力、交付和买方均无法核验；
2. 所谓部件没有独立采购市场，只能作为整机内部定制；
3. 关键零件要求我方不具备的认证、公差、追溯、保密或长期验证，且没有可进入伙伴；
4. 辅助设备只是 Agent 想象，用户并未反复执行该配套任务；
5. 已有设备厂以低成本原生集成，独立附件没有剩余价值；
6. 民用价格、责任或合规条件破坏原能力的承重机制；
7. 需要接触敏感主体、获取非公开技术、规避出口／安全限制或进入武器化用途；
8. 前 5 个对象没有一个能形成“明确买方＋具体配套任务＋可核接口”，停止扩样，不为凑技术雷达继续。

## 十二、固定输出

1. 90 秒结论；
2. `3.md` 中 10 个线索的身份恢复／淘汰表；
3. 5 张前沿能力雷达卡；
4. 成品、模块、零件、辅助设备四路线比较；
5. 哪些“军转民／技术来源”已核，哪些只是叙事；
6. 最值得杨亲自观察的最多 2 个对象；
7. 每个对象只给一条最便宜信息与停止线；
8. 偏差检查：技术决定论、规模幻觉、供应链万能论、军用光环、幸存者偏差、平台叙事、可进入性遗漏和确认偏差；
9. 来源总表。

本轮结束后不自动启动深度研究。只有杨从最多 2 个对象中点名一个，并说明它会改变成品／模块／零件／辅助设备中的哪条进入判断，才制作该对象的定向深度研究指令。
