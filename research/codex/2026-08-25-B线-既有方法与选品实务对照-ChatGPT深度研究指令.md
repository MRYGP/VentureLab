## PROMPT START

# 任务：B 线既有方法与消费品选品实务对照

## 0. 运行参数

- 指令版本：`v1.1`
- 运行日期：`2026-08-25`
- 研究范围：既有发明／产品改良方法，以及消费品选品、微创新变现和供应链选品实务
- 输出语言：简体中文
- 原始报告保存位置：`inbox/2026-08-25-B线-既有方法与选品实务对照-ChatGPT原始报告.md`
- 总目标：识别 VentureLab B 线哪些内容只是既有轮子的换名，哪些商业筛选也已有成熟做法，哪些空位仍需由自己的交易记录填补

## 1. 你的角色

你是方法史、产品设计、消费品选品和发明商业化的证据研究员。你的任务不是教授完整课程，也不是输出创业点子，而是进行一次**反重复核对**：

1. 给 B 线现有五个检索母题找到最接近的既有术语与原始出处；
2. 检查成熟发明方法是否处理供给可得性、渠道承重和复制后收益保留；
3. 检查消费品选品与发明变现实务是否早已建立同构的筛选、淘汰和结果统计。

不得因为某方法“可以勉强解释”一个案例，就写成该案例必然由该方法产生。事后归类、实际使用和因果作用必须分开。

## 2. 只回答三个问题

### Q1：五个母题分别借到了什么轮子

核对下表。每行只给最接近的 1—3 个既有术语，不扩成完整知识树：

| B 线现有母题 |
| --- |
| 技术名称 → 触发场景名称 |
| 隐藏缺陷 → 可见装饰 |
| 药不变 → 改变用药动作 |
| 多件步骤 → 一个动作 |
| 一次耗材 → 外壳＋补充装 |

每行必须回答：

- 最接近的既有术语、体系和提出者／机构；
- 原始定义与完整可点击来源；
- 属于发明原则、产品设计、人因／药械、市场定位、产品架构还是商业模式；
- 与 B 线母题真正重合的部分；
- 不能覆盖的部分；
- 是“原方法明确包含”，还是研究者的事后映射。

**Q1 正文最多一页。**不得逐条展开 TRIZ 40 原则、SIT 全套教材、SCAMPER 7 项或 Design Heuristics 77 项。

### Q2：成熟发明方法是否覆盖 B 线商业筛选问题

分两组检查这些具名体系：

**A 组：方案生成／工程优化**

- TRIZ；
- SIT；
- SCAMPER；
- Design Heuristics；
- Value Engineering / Value Analysis；
- Poka-Yoke / Mistake Proofing；
- DFMA。

**B 组：概念筛选／阶段门**

- Stage-Gate；
- 概念筛选与打分（Pugh matrix / concept screening and scoring）。

A 组在商业筛选问题上大面积不覆盖，可能只是职责范围不同，不构成“既有方法整体不覆盖”的证据。是否存在商业筛选空位，主要由 B 组和 Q3 的实务体系回答。若资料提到 desirability–feasibility–viability，只作为相邻线索，不扩成第三组。

对每个体系只判断它是否**明确、可操作地**处理以下问题：

1. 目标市场现有供给是否容易取得；
2. 中国／全球供应链是否已能低价复制；
3. 名称、演示、平台、零售、达人等渠道因素是否比功能更承重；
4. 被复制后品牌、IP、复购、渠道或授权是否还能保留收益；
5. 候选是否值得进入一次低成本真实交易实验。

输出一张覆盖矩阵，只能填：

- `明确覆盖`：原方法有正式步骤或判断字段；
- `部分涉及`：只处理相邻问题；
- `不覆盖`：已打开并核验该方法的核心文献，确认其定义或正式流程不处理该问题；
- `Ø`：未找到相关材料，或现有材料不足以判断。

“可以被使用者自行扩展”不算明确覆盖。每个 `明确覆盖` 必须给原始方法资料或同行评议来源；每个 `不覆盖` 也必须列出已经核验的核心文献。只搜索、未打开原文，一律记 `Ø`。厂商培训页只能证明其自述。

### Q3：消费品选品与微创新变现实务是否已有同构轮子

优先调查以下实务，不要求全部覆盖：

- Amazon／跨境电商公开选品框架与工具；
- 1688、义乌、深圳白牌或反向找源头的公开选品方法；
- 零售买手、DTC 消费品孵化器或公开商品评审流程；
- Quirky、Edison Nation 等发明提交、筛选、授权或变现服务；
- 有公开规则的产品众测、众筹前筛选或发明商业化平台。

至少找到 3 个具名体系，最多 8 个。每个体系固定回答：

1. 谁在使用、谁付款、靠什么收费；
2. 公开的候选来源、评分字段、淘汰门和决策流程；
3. 是否检查供给密度、价格带、销量／评论代理、渠道、广告成本、毛利、退货、合规、IP、复制速度和履约；
4. 是否公开成功率、失败率、入选率、真实销售、退款、关闭或破产数据；
5. 数据是具体 SKU、店铺、品牌、平台汇总还是公司自述；
6. 哪些部分可以直接借给 B 线，哪些依赖付费数据库、平台内部数据或大卖家资源；
7. 对杨这种低预算、先做封顶实验的个人是否适用；不能判断写 `Ø`。

Q3 的重点不是收集“选品技巧”，而是寻找公开可核的真实采用、付款、失败和淘汰数据。若公开成功率不存在，必须明确写 `Ø`，不能用 GMV、融资、用户数、评论数或案例故事替代。

对已经破产或曾经上市的发明变现平台，优先查法院／破产材料与 SEC 等正式披露。至少定向检查 Quirky 的 Chapter 11 材料，以及 Edison Nation 上市期间、后续更名主体的正式年报；尝试取得提交量、入选量、授权／版税收入，找不到就逐项写 `Ø`，不得用媒体摘要补数。

## 3. 证据标签

- `F-M`：真实市场行为，如可核销售、付款、授权、退款、关闭、破产或平台实际采用；
- `F-P`：方法原文、公司规则、产品页面、评分字段、收费和流程事实；
- `I`：由资料形成的合理推断；
- `H`：待验假设；
- `Ø`：没有找到或无法判断。

每条高负重结论必须注明：

- 页面标题与完整 URL；
- 访问日期；
- 来源属性：原作者／官方机构、同行评议、公司自述、平台资料、独立媒体、法院／监管、二手摘要；
- 利益关系；
- 原文是否已打开核验；
- 能证明什么、不能证明什么；
- 什么材料会让结论改判。

同一新闻稿的转载只算一个来源。搜索摘要不算已核原文。付费工具公开的营销评分表只能证明其主张，不能证明评分有效。

## 4. 来源优先级

### 方法体系

1. 创始人、原作者、正式基金会或标准机构原文；
2. 同行评议论文、大学研究团队和正式教材；
3. 专业协会；
4. 培训公司和咨询机构；
5. 二手博客与聚合摘要。

### 选品与商业化实务

1. 法院、监管、破产、公司注册与正式交易材料；
2. 平台公开规则、评审表、收费页和真实交易披露；
3. 商家或发明人可核的一手行为材料；
4. 独立媒体和研究机构；
5. 公司案例、营销文章和工具商自述；
6. 论坛、课程宣传和无法复核的经验帖。

低优先级材料可以提供线索，不能单独承担“有效”“提高成功率”或“值得复制”的结论。

## 5. 固定输出结构

### A. 90 秒结论

只回答：

1. 五个母题中多少可明确映射既有轮子；
2. 发明方法是否覆盖 B 线的商业筛选；
3. 选品实务是否已有更接近 B 线的体系；
4. 哪些可直接借，哪些仍必须由自己的交易记忆建立。

### B. Q1 一页对照表

按 Q1 固定字段输出，正文最多一页。

### C. Q2 覆盖矩阵

九个方法体系 × 五个商业筛选问题，并区分 A／B 两组。表后只解释最容易误判的 3 处。

### D. Q3 实务体系卡

至少 3 个、最多 8 个。前 4 个体系按七个固定问题完整输出；第 5—8 个只做一行登记：名称、使用者／付费方、公开筛选字段、是否公开结果数据、来源。

### E. 借用／保留／关闭清单

分别列出：

- `直接借用`：已有成熟术语或步骤，不再自创名称；
- `借用后改造`：现有方法只覆盖一部分，写清 B 线增加了什么；
- `仍需自建`：只能由杨自己的询价、付款、拒绝、退货和履约记录形成；
- `应关闭`：重复、无效或只会增加资料量的仓库设想。

不得提出建立完整方法库。只有某方法已被真实调用过至少 2 次，并至少影响过 1 次候选取舍，才可建议单独建方法卡。

### F. 来源总表

去重列出所有来源及其属性、利益关系、核验状态和承重结论。

### G. 最可能错的五处

至少包括：

- 把事后解释冒充发明过程；
- 把工具商营销字段冒充有效选品法；
- 把销量／评论代理冒充利润；
- 把平台或大卖家资源错误迁移给个人；
- 因公开失败数据缺失而产生幸存者偏差。

## 6. 停止条件

满足以下条件立即停止，不继续扩成百科：

1. Q1 五条全部找到可核原始定义，或诚实写明 `Ø`；
2. Q2 九个体系完成覆盖矩阵；
3. Q3 已有至少 3 个具名体系，每个都有公开筛选字段，并明确有无公开成功率／失败率；
4. 总正文原则上不超过 12,000 中文字；来源总表不计入；
5. 不整理任何体系的完整原则清单，不生成产品点子，不修改 VentureLab 模板。

若 Q3 找不到三个同时公开“筛选字段＋结果数据”的体系，可以用公开筛选字段完整但结果为 `Ø` 的体系补足，并把“结果数据缺失”本身作为结论，不得继续无上限搜索。

## 7. 禁止外推

- 找到既有术语，不证明该方法产生了 B 线案例；
- 找到公开评分表，不证明评分表有效；
- 找到成功公司，不证明其筛选流程造成成功；
- 找到中国供应链同类，不证明存在需求或杨可以进入；
- 找不到公开失败率，不证明失败率低；
- 商业筛选已有先例，不证明 VentureLab 没有价值；它只改变“哪些部分应借、哪些必须自己验证”。
