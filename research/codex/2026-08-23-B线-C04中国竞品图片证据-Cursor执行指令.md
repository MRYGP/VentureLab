# Cursor 执行指令：C04 中国竞品与图片证据样例

## 0. 本轮裁决

- B 线的具体物理产品“中国竞品核验”原则上都要有图片，因为形态、包装、集成方式和替代关系往往无法仅靠文字核验。
- 图片是证据附件，不是装饰，也不是销量、付款或需求验证。
- 纯财务、组织或失败机制报告若视觉形态不承重，可以不强制配图；缺图时写 `Ø`，不得为了凑数使用无来源图片。
- 仓库正式案例编号沿用 `C04-Scrub Daddy`、`C05-PopSockets PopGrip`，不得另造 `B-01/B-02`，避免出现两套编号。
- 本轮只做 `C04-Scrub Daddy` 一个流程校准样例，不把“找到仿品”本身记为新判断。交付并经 Codex 证据审计、杨终验后，才决定是否放行 `C05` 及其余案例。

## 2. 任务性质与边界

本任务是定向公开资料核验，只回答中国市场是否存在同类、仿制或功能替代，以及公开价格和平台显示口径。它不是需求验证、候选晋级或交易实验。

只访问无需登录的公开页面。不登录、注册、付费、联系卖家、询价、拿样、发布、报价或售卖，不绕过验证码或访问限制。

## 3. C04 必答问题

1. 中国是否存在被明确对标为 Scrub Daddy 的仿制或同构产品？
2. 是否存在更便宜但不同构的功能替代：普通百洁布、双面海绵、纳米/魔力擦、硬质清洁擦？
3. “随水温改变软硬度”是否是中国供给中的真实产品属性，还是仅有笑脸外形或商家文案？
4. 可公开观察到的玩家、渠道和价格带是什么？
5. 能否取得平台显示的月销、已售或评价数？取得则注明页面、日期和口径风险；没有则写 `Ø`。
6. 哪一种解释更符合现有证据：同构仿制、低价替代、需求差异，或暂时无法判断？推断必须标 `I`。

建议关键词：`Scrub Daddy`、`笑脸海绵`、`冷热水变硬软海绵`、`可变硬度海绵`、`双面清洁擦`、`纳米海绵`、`魔力擦`、`油污擦`。

## 4. 图片证据标准

VentureLab 远端已确认是公开仓库。最终可在 `evidence/assets/B线图片/` 本地缓存 2 至 4 张有判别价值的图片，但该目录必须保持 Git 忽略，不得暂存、提交或推送；仓库台账只保留 URL、访问日期、描述与证据边界。

图片优先覆盖：

1. 原品官方图：展示原品形态及温度响应主张；
2. 中国同构/仿制图：展示笑脸外形或同类功能主张；
3. 中国功能替代图：展示纳米海绵、双面海绵等不同构替代；
4. 必要时的平台页面截图：用于保存当日价格或平台显示口径。

每张图片必须登记：本地缓存路径（不入 Git）、原始页面 URL、图片直接 URL（能取得时）、访问日期、来源属性、版权/使用说明、能证明什么、不能证明什么。商品主图只能证明页面展示与商家主张，不能证明真实性、销量、付款或效果。

优先下载原始图片；若页面数据会变化，可另存公开页面截图。不得裁掉店铺名、商品名、价格或口径字段等必要上下文。不得保存登录态、账号、收货地址或其他个人信息。下载失败就保留 URL 并写明失败，不得用搜索缩略图或 AI 生成图代替。

文件名：

```text
C04-ScrubDaddy-original-01.jpg
C04-ScrubDaddy-china-analog-01.jpg
C04-ScrubDaddy-china-substitute-01.jpg
C04-ScrubDaddy-platform-01.png
```

## 5. 证据纪律

- `F-M`：可核的真实市场行为事实。
- `F-P`：页面在售、标价、商品主张、平台显示字段等事实。
- `I`：由页面组合得到的解释。
- `H`：待验证假设。
- `Ø`：没有找到。

平台显示的月销、已售、评论数只能记为 `F-P（平台显示口径）`，不得记为付款验证 `F-M`。必须注明刷单、口径不透明、时间窗口和价格波动风险。

每条高负重结论都写：完整来源、来源属性与利益关系、访问日期、原文核验状态、能证明什么、不能证明什么、反证条件。
