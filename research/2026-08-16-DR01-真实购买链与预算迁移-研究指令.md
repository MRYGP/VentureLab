# DR01｜真实购买链与预算迁移研究指令

> 日期：2026-08-16
>
> 状态：指令已建立，研究未启动
>
> 优先级：1
>
> 目标：核验谁曾为足够同位的任务付钱，以及钱从哪笔预算迁移

## 一、核心问题

在“帮助个人选择或验证一条赚钱／创业／职业变现路线”这项具体任务上：

1. 是否存在个人自费的可核购买？
2. 是否存在机构、雇主、政府、社群或分发方付款？
3. 免费／补贴供给服务的任务、用户和结果是否与收费供给相同？
4. 付款购买的是判断、培训、合规课时、代办、客户、渠道、环境、责任还是持续陪跑？
5. 即使购买链存在，杨是否有合法、可重复且可承受的进入路径？

不允许把“职业咨询”“创业培训”“孵化服务”等大类名称自动视为同位。

## 二、事前待验命题

| 编号 | 命题 | 初始等级 |
|---|---|---|
| P1 | 存在个人为路线选择／验证本身支付现金，而非主要购买课程、社群、代做或客户渠道 | `H/Ø` |
| P2 | 存在第三方按人头或按项目为同位判断／验证任务付款 | `H/Ø` |
| P3 | 成熟市场的免费／补贴供给与个人收费供给服务的是不同分层用户或不同任务 | `H` |
| P4 | 某类付款链同时存在非人情、可重复的进入路径 | `H/Ø` |
| P5 | 机构购买的主要交付可能是标准化课时或合规凭证，而非个性化判断 | `H` |

执行者在检索前补写自己的预测和最可能推翻预测的证据，禁止检索后倒填。

## 三、任务同位分级

每个样本先判级，再讨论价格和规模：

### L1｜同位

触发是个人需要选择／排除／验证赚钱或经营路线；交付包含个性化判断或低成本市场验证；付款明确针对这项任务。

### L2｜邻近

职业规划、创业培训、商业教练、孵化、社群或代运营等，只覆盖部分任务。必须指出缺了哪一段，不能用大类相似代替同位。

### L3｜外部强制

付款主要为了被裁安置、领取补贴、完成课时、贷款／签证／加盟审查或采购验收。它可以证明预算和触发结构，不能直接证明个人主动选路付费。

## 四、研究范围

### 中国优先

- 可核定价、合同、采购、退款、判决、行政处罚或真实付款材料；
- 个人自费的职业／创业判断与验证服务；
- 社群、培训机构、孵化器、园区、企业转型／安置等付款结构；
- 政府购买创业指导、就业／转型支持时，区分培训课时、咨询诊断、陪跑和代办；
- 每条机构链同时核进入要求：资质、关系、采购周期、投标、定制和责任。

### 成熟市场反证

- 免费或补贴的创业／小企业咨询；
- 收费创业顾问、职业教练或商业计划服务作为对照；
- 比较用户、任务、容量、等待、服务深度、触发与资金来源；
- 免费供给存在不等于个人支付意愿低，必须寻找分层和替代证据。

任何机构、项目或行业名称在取得原始来源前都只是检索线索，不是事实。

## 五、购买链记录模板

| 字段 | 必填内容 |
|---|---|
| 具体触发 | 为什么此时购买 |
| 受益者／使用者 | 是否同一主体 |
| 付款方／预算所有者 | 真实主体与预算科目 |
| 签约者／分发方 | 谁批准、谁拥有第一批人 |
| 责任承担者 | 判断或交付失败由谁承担 |
| 购买任务 | 判断、培训、验证、执行、渠道、责任或其他 |
| 价格与计价 | 实付／合同价／挂牌价必须分开 |
| 已有行为 | 付款、采购、续约、退款、流失或组织投入 |
| 结果措辞 | 保证什么、不保证什么 |
| 进入条件 | 资质、关系、周期、获客和定制要求 |
| 同位等级 | L1／L2／L3及理由 |

## 六、来源优先级

1. 政府采购合同、预算／决算、监管、法院和正式交易材料；
2. 真实合同、付款、退款或客户一手材料；
3. 公司定价、条款和正式公告；
4. 独立评估报告；
5. 可信媒体与管理层访谈；
6. 投资方、行业协会、自述报告；
7. 投诉、论坛和评论，只生成假设。

培训人数、注册人数、政府拨款总额、用户数和课程标价均不能单独证明同位付款。

## 七、工作上限与停止条件

- 候选样本不超过15个；
- 深卡不超过6张，至少尝试覆盖个人自费、机构付款、免费／补贴三种结构；
- 定向检索不超过18次，原文抓取不超过6份；
- 连续三个检索回合只有宣传、聚合或同源转载时停止该分支；
- 找不到L1时明确写`Ø`，不得用L2／L3补位；
- 找到机构预算但找不到杨的进入方式时，付款链与进入链分开记，不升级候选。

## 九、禁止外推

- 机构为职业安置付款，不等于机构会为个人赚钱路线付款；
- 政府购买课时，不等于购买个性化判断质量；
- 免费公共服务存在，不等于个人不愿付费；
- 一次采购不等于续约、效果或可复制进入；
- 有预算不等于杨有渠道；
- 投诉、差评或退款个案不等于普遍死因。
