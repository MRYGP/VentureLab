# VentureLab · 创业机会联合研究库

> 建立日期：2026-08-01
> 本地路径：`D:\VentureLab`
> 当前状态：仅本地 Git 仓库，未配置远端

## 一句话定位

在 PB 的神圣假设与 SK 的商业判断之外，建立一个面向全球产品、失败样本和真实市场证据的公共研究层。

## 当前任务

第一阶段不是选创业前三，而是扩充样本宇宙：

- 建立 50 个轻量外部样本；
- 从中形成 12 个教科书级产品深卡；
- 建立至少 10 个真实墓碑；
- 归纳 6—8 种跨行业结构模式；
- 提出 8—12 个研究方向；
- 由 Codex 与 Claude 独立研究后交叉质询。

## 目录

| 目录 | 用途 |
|---|---|
| `inbox/` | 尚未完成来源审计的原始发现 |
| `products/` | 活体产品卡、产品索引和商业结构 |
| `tombstones/` | 停运、死亡、转型、被收购或被并入样本 |
| `patterns/` | 跨产品、跨行业可迁移机制 |
| `opportunities/` | 联合研究候选，不等于正式创业结论 |
| `evidence/` | 来源审计、付款、续约、流失和单位经济证据 |
| `research/codex/` | Codex 独立研究报告 |
| `research/claude/` | Claude 独立研究报告 |
| `research/cross-review/` | 双 AI 互相攻击、冲突与联合裁决 |
| `templates/` | 产品卡、墓碑卡和研究表模板，按需建立 |
| `_archive/` | 被取代或停止使用的材料 |

## 默认读取顺序

1. `00-宪章.md`
2. `README.md`
3. `AGENTS.md`
4. 当前任务直接相关的索引或报告
5. 对应产品卡、墓碑卡和证据文件

禁止为了找方向而无目的全仓扫描。

## 默认研究流程

1. 外部发现先进入 `inbox/`；
2. 核清主体、产品、服务、时间和来源；
3. 分别沉淀至 `products/` 或 `tombstones/`；
4. 高负重结论进入 `evidence/` 做来源审计；
5. 跨样本规律进入 `patterns/`；
6. 只有同时具备结构变化与商业问题的方向才进入 `opportunities/`；
7. Codex 与 Claude 独立研究后在 `research/cross-review/` 交叉质询；
8. 杨确认后，成熟结论才可向 PB 或 SK 交接。

## 证据规则

统一使用：

- `F-M`：真实市场行为；
- `F-P`：公司、项目或仓库内部事实；
- `I`：合理推断；
- `H`：待验假设；
- `Ø`：无材料。

只有 `F-M` 能对商业排序产生强加分。官网客户案例、投资方材料和媒体报道均需保留来源属性与利益关系。
