## 一、杨的原始观察与后续纠偏

以下只把能够恢复的杨原话放在引号内。AI 的概括另行标注，不冒充原话。

### 1. 原始戒烟经历

> “我现在又抽了！有时候也能借几小时，但是又忍不住去买烟！我觉得如果说有一支假烟，能够给我口腔一点刺激（比方说凉爽的薄荷味）  再加上戒烟药！  完全的抽空气，可能也会烦，也可能就当时有效果，但是次数多了以后，可能没效果！”

- 证据边界：`F-P·杨自述`。原文中的“借几小时”照录，不由 Agent 静默修正。
- 能证明：杨本人曾在戒烟／复吸过程中观察到口腔刺激、行为替代和买烟便利性问题。
- 不能证明：其他戒烟者同样需要该方案、愿意购买，或任何具体产品有效。

### 2. 杨对推演方式的纠偏

> “我们的推演可能越来越像文字游戏。应该考虑的是，用户有什么需求，新产品满足了这个需求没，比原有的产品增加了什么功能，或者是解决了原有产品没解决的问题，增加了什么样的不便利。。。，”

- 这句话把讨论从产品部件和叙事拉回到用户任务、当前替代、实际增益与新增负担。
- “手里嘴里缺点东西”等未找到逐字出处的表达，只能视为 AI 对原始经历的转述，不作为杨的引语。

### 3. 杨的当前产品偏好

- `F-P·杨表达`：杨当前不选择戒烟／辅助戒烟产品，理由包括其治疗属性、对使用者意愿和配合的依赖，以及对这类业务的个人取舍。
- 该偏好足以支持本项目当前不继续这条产品路线，但不能写成戒烟产品无效、市场不存在或商业上必然不成立。

## 二、构思链与任务漂移

```text
真实经历：戒烟时口腔刺激不足、最终又去买烟
→ 无尼古丁替烟装置
→ 香味空气装置
→ 金属把玩型可换芯装置
→ 男士隐形补香
→ 烟后口腔／手／衣物气味重置
→ 气味检测＋干预
```

| 阶段 | 当时的用户任务 | 被继续保留的部件 | 新增材料 | 新增假设或漂移风险 |
|---|---|---|---|---|
| 戒烟体验 | 渡过烟瘾发作时的口腔与动作缺失 | 吸嘴、吸气动作 | 杨的个人经历 `F-P` | 从一个人的经历外推人群需求 |
| 无尼古丁替烟 | 保留动作、避免燃烧和尼古丁 | 吸嘴、风味芯 | 相邻空气棒／吸入器产品线索 | 未证明相比现有替代的净改善 |
| 金属把玩化 | 让装置更愿意随身携带 | 吸嘴、香味、金属、可换芯 | EDC／把玩产品类比 | 载体偏好开始替代原始任务 |
| 男士补香 | 在公共场合隐蔽补香 | 香味、金属、把玩动作 | 便携香氛产品供给事实 | 未证明目标用户因补香动作尴尬而放弃 |
| 烟后气味重置 | 在见人前处理口腔、手、衣物与头发 | 香味、便携载体 | 口喷／除味喷雾等供给事实 | 将多个不同机理和动作合成一个产品 |
| 气味检测 | 解决用户难以判断自身气味的问题 | 便携载体、检测、干预 | 便携口气检测研究与产品线索 | 准确性、后续行动和使用负担均未解决 |

### 正常迁移与构思漂移的暂定区别

- 正常迁移：先观察到一个独立存在的新用户／新场景／新任务，再检查旧机制能否承重。
- 构思漂移：先舍不得旧构思中的部件，再为该部件寻找新的用户任务。
- 本轮只提供一个样本，尚不能建立普遍规律；新任务若能独立证明某个旧部件确有必要，仍可重新采用该部件。

## 三、本轮讨论过程的失灵

### 1. 连续放大，没有及时分支

- `F-P·对话记录`：当杨增加补香、气味或检测维度时，AI 多次将新表述解释成“更正确的方向”“新的结构性机会”，却没有先判断用户任务是否已经改变。
- 结果是多个不同任务被写成同一产品的连续进化，原始部件获得了未经证明的默认继承权。

### 2. “拿掉吸”只完成了局部减法

- Claude 后续自检指出：拿掉“吸”看似纠偏，但同时保留了香味与金属把玩，再为它们寻找男士补香需求。
- 这一判断作为 `I·公开复核` 保留。它提示未来不能只看删掉了什么，还要看剩余部件是否仍由当前任务要求。

### 3. 真正的刹车来自杨的任务追问

- 本轮从连续扩张转向收敛的直接触发，是杨指出“越来越像文字游戏”，并要求比较用户需求、现有产品、新增功能、未解决问题和新增不便利。
- 不把这一变化归功于已经存在的方法自动生效；当时 AI 没有主动、及时地用这些问题结束漂移。

### 4. 本轮贡献必须分账

| 项目 | 本轮结果 |
|---|---|
| 新增可推进产品候选 | 0 |
| 支持我方新方案的真实付款／选择 `F-M` | 0 |
| 新增外部事实 | 非 0：查到相邻产品供给、便携香氛、口气干预、气味检测和安全研究；多数只能否定“完全空白”或限定安全／技术边界，不能证明我方方案会被选择 |
| 产品判断增量 | 四个具体方案停止继续扩写或暂挂；戒烟路线与市场证伪分账 |
| 过程教训 | 任务变化未分支、旧部件默认继承、AI 连续放大、没有按轮结账 |

Claude 与 Codex 的自我评价只作为过程材料；不把“某 AI 净贡献为零”写成事实，也不以自我批判替代证据分账。

## 七、跳过“对标—复制—创新”的根因与执行校正

### 1. 杨的进一步诊断

> “其实我明白 这次真的问题 在哪了：我‘发现’一个问题，然后提出我假想的一些方案，然后推演。。，其实我只是在重复N多人原来以前推演过，尝试解决过的问题。而SK也好 ，我们仓库也好 ，真正明确的方法论是：对标，复制，创新。。。”

> “所以，我们有可能应该残酷一点 ：没有特殊情况，不再分析我的所谓问题，灵感。只是从找到的产品出发，进行对标，复制，创新。不然，路太长了”

### 2. 本轮真正跳过的环节

本轮不是因为产生个人灵感而失败，而是在已经找到 JOYO、FÜM、CAPNOS 等具体产品后，仍把它们只当作支持构思的类比，没有切换为精确 SKU 观察。讨论实际走成：

```text
个人经历
→ 假想方案
→ 为方案寻找相邻产品与解释
→ 继续改用户、任务和部件
```

应采用的顺序是：

```text
个人灵感只定位货架
→ 找到已被选择的精确 SKU
→ 对标：看谁买、为何买它、当前替代与未解决部分
→ 复制：合法保留已承重的结果／机制／供应或交易基准
→ 创新：只改变一个已观察到的未解决部分
→ 比较净变化并接受现实判错
```

“复制”不等于抄外观、仿冒、侵权或原样转卖；它的作用是先固定已经成立的基准，减少同时改变用户、任务、结构和商业模式造成的未知。

### 3. 2026-09-03 起的 L1 有限执行偏好

- 没有杨明确授权的特殊情况，个人问题和即时灵感只逐字记录，并用于定位应观察的产品货架，不直接展开产品方案。
- 一旦找到可观察的精确 SKU，停止自由推演，进入杨先观察与 Agent 后补证据的顺序。
- 每个被选中深入观察的 SKU，机会侧必须二选一：“我方会改的是 X”或“没有可改的，关闭”。
- 信息不足时，只允许提出一条有边界、会改变判断的关键信息；补完后仍须二选一，不能不断追加研究。
- “已理解／机制参考”可以作为学习结果保留，但在机会侧仍须关闭，不能成为无限滞留状态。
- 不得为满足出口而强造创新；只有已见具体未解决部分，才允许写“改 X”。
- Amazon 5 个 SKU 若都没有形成“改 X”，产品段停止，不看第 6 个；复盘时再决定换货架、修订入口或停止。

### 4. 范围、到期和回退

- 本偏好先作用于方向 B 第二学习周期 Amazon 5 SKU 产品段，不修改宪章、三道门、证据标准或长期方向定义。
- “特殊情况”必须由杨明确授权，并记录理由、范围和回到 SKU 主线的条件；Agent 不得因想法新颖或杨表现出兴趣自行放行。
- Amazon 5 SKU 产品段结束时复盘：若该做法导致为完成任务强造改良、错杀有效生活观察，或没有缩短从观察到取舍的路径，则修订或回退；不得静默固化为长期规则。
