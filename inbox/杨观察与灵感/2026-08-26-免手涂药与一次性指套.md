# 杨观察：免手涂药与一次性指套

> 日期：2026-08-26
> 来源：杨在日常使用动作中的直接观察
> 状态：`杨观察·待定向核验`
> 边界：原始产品问题线索，不是正式案例、医疗建议、发现门结论或自有方案假设。

> 2026-08-26 二次收缩：杨认为滚珠、按摩头和通用给药附件过度设计。当前优先观察的最小方案只是**一次性指套**：一个涂药手指用一个，需要两个手指就用两个，只解决手部卫生与残留问题，不主动解决按摩、定量或给药结构。

## 一、原始观察

平常把药膏或药液挤到皮肤上以后，往往还要用手涂匀，有时还需要按摩几下。这样手会接触药物；洗手之前的黏、凉、热、气味或残留感令人不舒服，还可能碰到衣服、手机、门把手或其他皮肤。

肛周或直肠用药会进一步放大可达性、隐私、卫生、剂量和清洁问题，但它与普通皮肤涂药不是同一个使用场景，不能共用一个未经专门设计的通用工具。

## 二、当前问题拆分

### A. 普通外用皮肤

固定动作链：

```text
开盖／挤药
→ 定位到皮肤
→ 涂匀
→ 可能按摩至吸收
→ 手上留下药物
→ 在碰其他物品前洗手
```

当前可观察摩擦：

- 手部污染和洗手前的不适；
- 单手或难以够到背部等位置时操作不便；
- 涂抹面积、厚薄和按摩压力难以稳定；
- 涂抹头自身是否容易清洁、堵塞或把皮肤污染带回容器。

当前最小应对不是新涂抹机构，而是涂药前套上一次性指套、涂完即弃。它保留手指原有的触觉、涂匀和按摩能力，只隔离药物残留。

### B. 肛周外用

除手部污染外，还增加：看不见、难定位、姿势不便、皮肤敏感、一次性卫生和隐私处置。一次性指套比滚珠更接近原有用药动作，也更容易保留手指触觉；但它是否比纱布、棉签或洗手更方便，仍为 `Ø`。

### C. 直肠内用

这是专门给药路径，涉及剂量、插入深度、润滑、黏膜损伤、交叉污染和清洁。只能研究与特定药品说明书配套的专用 applicator、栓剂或一次性给药器；不能把普通滚珠、按摩头或外用涂抹附件迁入直肠。

## 四、当前判断边界

1. `F-P`：免手滚珠、按摩滚珠、定量外用容器、肛周手指涂抹、直肠专用 applicator 和指套方案都已经存在；Rectogesic 的正式说明书直接允许使用指套或覆膜手指。
2. `I`：当前最小问题不是“如何把药放上去”，而是**保留手指涂匀和按摩能力，同时用一次性隔离物避免药物留在手上**。
3. `Ø`：不知道这个问题在哪些具体药品、目标人群和场景中重复发生，也不知道用户是否愿意为附件、包装变化或一次性耗材付钱。
4. `Ø`：不知道机会应是独立售卖普通指套、按次小包装、随药附送，还是根本没有单独付费价值。
5. 肛周外用和直肠内用必须分成两个研究对象；直肠内用默认高风险，不作为普通消费附件的快速迁移方向。
6. 指套是现成轮子，本观察不主张发明指套。若有新增价值，更可能发生在材料、尺寸、按次包装、易穿脱和与具体药品配套的交付方式上。

与一次性吃东西手套的区别：吃东西手套主要覆盖整只手，目的是避免食物与手相互污染；本观察关注的是**只覆盖正在执行精细动作的一两个手指，同时保留其余手掌的触觉、散热和抓握**。两者共享隔离材料，但使用动作、覆盖面积和包装数量不同。

当前可继续观察的迁移，不等于机会：

- 涂胶、环氧树脂、润滑脂、鞋油、染膏和难洗颜料；
- 宠物耳部、牙齿、眼周或局部用药护理；
- 清理狭窄缝隙、局部污渍或令人不愿直接触碰的东西；
- 保护伤口、绷带和裂口，同时保留其余手指活动；
- 精密维修、收藏品、镜片、首饰和模型操作，避免汗液和指纹。

`I`：潜在新增价值不太可能来自“还有没有别的用途”，因为用途已经很多；更可能来自**某个具体任务是否值得把通用工业指套重新做成容易理解、按次取用、材料合适的消费组合**。

`Ø`：尚未核中国电商中的卖家密度、价格带、销量口径、差评、起订量和小包装供给；也不知道上述任何一个场景是否具有独立付款强度。

## 六、下一轮只核五问

1. 哪些具体药膏最常要求手指涂匀或按摩，且手部残留最令人不适？
2. 用户是否已经用一次性手套、指套、保鲜膜、纸巾或棉签解决；为什么没有成为稳定习惯？
3. 用户评论里是否反复出现“必须洗手”“黏手”“刺激手”“碰到眼睛／其他部位”等原句？
4. 独立指套、两只装按次小包、随药附送三种交付方式中，市场上分别已有多少等价方案？
5. 对肛周外用，指套是否已经足够；若不够，剩余问题究竟是卫生、穿脱、破损、尺寸、剂量还是可达性？直肠内用只按具体药品说明书研究。
