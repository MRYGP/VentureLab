## 一、这份文件只做什么

本文件是 B-18 的轻量执行计划与日志。杨的羽毛球擦镜痛点已经明确，不再重复确认“有没有需求”。现在先取得污染、清洁、固定与佩戴事实，为主记录中的三条路径分流：路径 1 截汗固定发带，路径 2 擦镜眼镜带，路径 3 两者组合。路径 2 再比较整带可擦、内藏镜布、两者都有；镜腿中部／尾端和黄色外观另作变量，不一次改变全部结构。

当前执行仍是已有装备下的自然记录。普通发带只测试截汗基准，不等于已测试路径 1 的新固定连接；普通镜布只测试清洁与取用，不等于已测试路径 2；同场戴两种普通带也不能证明路径 3 的自有整合成立。两名内部协作者的既有顺序与证据边界保留。

杨的主记录属于 `F-P·杨自测`；两名内部实习生的自然观察属于 `F-P·内部自测`。这些记录可以淘汰结构和动作假设，不能证明陌生用户有同样任务、会在每次运动前主动安装或愿意付款。太阳镜、阅读镜、日常好找和其他运动均不在本阶段扩张。

## 二、当前唯一任务

完成 **3 次轻量羽毛球记录**，只用于判断是否需要第一样件及其对应路径／最小变量，不要求三场选出赢家、验证三种产品或得到市场结论。不为了测试刻意弄脏、多擦、多推镜；一次事件没记清就写“大约”或“没记清”，没有发生写 `0`。天气、时长和出汗程度差异明显时标为“不可直接比较”，需要时以后再交替重复，不为了凑结论无限延长。

### 2.1 内部测试者与执行顺序（2026-10-07 新增）

1. **杨继续承担羽毛球主记录。**原三场顺序和判断边界不变；至少先完成一场照旧基线，再决定同场景实习生使用哪一项记录条件，避免三个人同时改变不同变量。
2. **同样打羽毛球的内部实习生只做重复观察。**她先记录自己目前真实的眼镜污染、清洁、滑动、推镜和取用动作，再按杨确认的单一条件重复；不得因她的结果与杨相同就升级为外部用户证据。
3. **有健身习惯的内部实习生只作相邻场景迁移观察。**先记录正常健身中是否自然出现镜片污染、滑动、推镜、清洁或停下处理；健身动作、持续时间、出汗与器械安全边界单独记录，不与羽毛球表格直接合并，也不据此扩张目标市场。
4. **参与和停止边界。**内部实习生参与自测须自愿；出现视觉明显变化、疼痛、皮肤损伤、勾挂风险、镜架连接异常或对正常运动产生干扰时立即停止。暂停、拒绝某个条件或报告无事件，不影响实习评价。
5. **证据边界。**三人均是团队内部、都戴近视眼镜且有运动习惯，属于便利样本。结果统一标为 `F-P·内部自测`；它可以决定是否值得制作下一步最小样件，不能证明陌生用户采用、付款、复购或市场规模。

三场按以下顺序执行：

1. **照旧基线：** 保持当前真实装备和处理习惯，观察污染来源与完整恢复动作。
2. **受保护普通镜布强对照：** 使用已有且确认适合镜片的普通镜布，放入现有小密封袋或其他现有保护物，再放到真实可及位置；优先使用球裤／运动服中实际愿意使用的口袋，其次是场边固定位置。密封袋是本轮可用的保护方式，不是最终产品规格；用后湿布需要取出展开干燥，不把湿布封回后仍然洁净、可再次使用当作前提。若没有合适镜布、保护物或可及位置，就记录 `Ø`，不因本文件自动购买。
3. **普通发带分流对照：** 仅在杨已经拥有并愿意正常佩戴普通运动发带时执行，尽量沿用第二场同一块镜布、同一种保护物和同一放置位置，其他既有装备也尽量保持相同，再观察额头汗污染是否减少；若没有发带，则根据前两场最大的未知重复“照旧基线”或“受保护镜布”，不自动购买。若清洁条件无法保持相同，明确记下变化；分别记录污染事件是否减少、每次恢复是否更方便，不能把组合结果归给其中一个。

## 四、预先写下的解释边界

1. 杨的个人擦镜任务已成立；若 3 次中通常只擦 0—1 次，本轮没有足够理由为多页／连续擦镜增加复杂度，第一样件优先简单版本；这不永久关闭多次清洁路线，也不自动关闭单次应急清洁面。以后出现真实重复失效时可凭新事实重开，不刻意制造多次擦拭。一次擦拭也仍需记录湿手污染、握持面积和保护收纳是否失败。
2. 若口袋／场边的密封普通镜布已经能快速恢复清晰且没有明显代价，眼镜带和发带附着结构都必须证明额外净便利；不得因构思完整而降低这个对照标准。
3. 若自然找镜事件不发生，只表示本阶段没有给醒目路线增加证据。醒目仍须兼顾运动佩戴后的美观，不能只追求亮色。
4. 若普通发带在可比较条件下减少额头汗污染，只说明杨个人场景中的上游截汗可能有效；需要重复后才提高可信度，也不能外推陌生用户或整个市场。雾气、手印、雨水／飞溅和残余污染继续分账。
5. 当前允许四种结果：受保护普通镜布在本轮个人场景中已足够；眼镜固定带值得作为清洁芯载体比较；发带／护腕／球包挂件／衣物擦片等计划内运动载体更值得比较；不同载体只在各自场景成立。选中第一样件的载体不等于该载体已经胜出；按杨真实装备习惯选择，不因眼镜带是原构思就优先保留，也不把载体家族的整理关系当作使用成本相同。不得预设两件套。
6. 未来样件真正的“保留”不是日常永久挂在眼镜上，而是无人提醒时每次运动主动带上或装上、自然使用、运动后愿意拆洗／展开干燥，并在下一次运动再次使用。
7. 若只有某一个功能产生净改善，允许收缩成更简单产品，不用固定、防掉、醒目或其他载体故事保住无效清洁结构。
8. 出现明显视觉变化、疼痛、皮肤损伤、勾挂或连接失效，暂停对应结构；砂尘或硬颗粒镜片不做直接干擦试验。
9. 带子本身能擦与内藏镜布不自动构成双重保障。后续只有独立备用仍干净，或“先吸水、后精擦”确实产生净改善，才有理由保留两套清洁面；本轮不先制作双清洁结构。

## 五、分阶段执行计划（第 1 步沿用现有授权，样件与外部动作另行授权）

| 步骤／权限 | 最小动作与对照 | 只决定什么／进入下一步条件 |
| --- | --- | --- |
| 1｜现有授权内 | 杨完成三场，内部协作者按 2.1 重复／迁移观察；汇总污染、镜布清洁与取用、截汗、滑动／推镜和佩戴代价 | 分清真实任务，不以普通装备结果冒充新结构效果；确认无事件写 `0`，未知保留 `Ø`，条件不可比单独注明 |
| 2｜事实回传后的内部整理，无采购／制作 | 从路径 1／2／3 选择一个值得比较的最小结构；写下“现成办法哪里不足、只改变什么、与谁比较、什么结果不保留” | 可以不选样件；只有额头汗问题时先看普通发带，组合只在两项任务同时需要时保留 |
| 3｜最小样件另行授权 | 路径 1 与普通发带／普通固定带比较新增固定增量；路径 2 与受保护普通镜布比较，清洁 A／B／C、镜腿尾端／中部先只选必要变量 | 列明现金、人工时间、周期与责任后再启动；不同时制作三条路径，不用黄色差异解释清洁收益 |
| 4｜样件条件内逐项比较 | 同材料优先；完整记录摘镜→取布→擦净→放回→戴好，再看接口滑移、佩戴、拆洗和干燥 | 判断载体净便利；JIBS 可作为内藏镜布动作对照，取得实物仍需另行授权 |
| 5｜有具体未知才追加，另行授权 | 自然重复失效后比较独立洁净备用／多面隔离；同时需要截汗与清洁时再比较路径 3 的分开佩戴与一体整合 | 两处清洁面是否真实独立，组合是否省装备／动作；不让两套固定系统同时绷紧 |
| 6｜样件授权范围内 | 连续 3—5 次运动观察主动安装、自然使用、佩戴和洗护，以及下次再次使用 | 新鲜感后是否仍愿保留；内部结果仍不能证明陌生用户采用或付款 |
| 7｜外部与交易另行授权 | 在具体方案与行动条件收敛后，再安排同情境陌生用户和带价格验证 | 外部采用、付款、交付与收益；本计划修订不自动通过三道门或进入 TradeLab |

三场结束后，按观察选择第一样件需要改善的环节，不强制产出样件：

| 实际观察 | 本轮下一步判断 |
| --- | --- |
| 普通镜布保护、携带、取用和清洁均方便，未见明显代价 | 暂无理由增加附着结构，不因已经选中 B-18 就强做样件；不外推为整个市场没有需求 |
| 普通镜布清洁有效，但取用／放回麻烦 | 第一待测结构优先改善载体、开合和握持动作 |
| 清洁面首次有效，后续因湿污失效 | 保留干净区／已用区管理假设，再判断是否需要独立清洁面 |
| 普通镜布首次也未能恢复清晰 | 先分清污染、材料、湿手或动作问题，不把增加页数当成默认答案 |
| 普通发带减少了大部分汗液污染 | 先判断残余事件是否仍值得随身清洁件；不能把一场差异写成稳定效果 |
| 已有发带截汗后仍有滑动／推镜，现有固定方式又有明显代价 | 路径 1 值得提出最小连接对照；普通发带效果不证明新固定连接已成立 |
| 截汗、固定与残余污染清洁同时需要 | 路径 3 保留为条件组合；后续比较能否少戴一条带或少做动作，而非直接确定两件套 |
| 清洁有改善，但新增穿戴负担明显 | 换载体或缩小结构，不靠其他功能抵消佩戴代价 |
| 未发生自然污染、记录不清或条件不可比 | 保留关键空格，点名一个仍会改变结构选择的未知；三场不是必须选出赢家的期限 |

JIBS 是擦镜路线的首要直接对照；Chums／Spudz 是两件式随身镜布对照；竞品与专利证据统一留在 B-18 主记录，不在本日志重复维护。当前不一次购买四个品牌。若第 1—2 步留下明确缺口，再重新核实可得性、现金与最小采购组合并申请授权。
