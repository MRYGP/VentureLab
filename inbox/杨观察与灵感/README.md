## 记录纪律

1. 先写杨看见了什么、为什么觉得奇怪，再补代理查证；不得用代理总结覆盖原始观察。
2. 每条观察可以包含产品改良、跨人群迁移、跨场景迁移、新任务和商业包装联想。
3. 允许结论是已有竞品、需求太弱、不可进入或暂时说不清；不得为了保留灵感而强行形成机会。
4. 进入本目录不等于通过发现门，不建立 `Cxx`、`B-Hxxx` 或 TradeLab 编号。
5. 只有杨确认值得继续，且补到真实购买或重复行为材料后，才移交现有三道门流程。
