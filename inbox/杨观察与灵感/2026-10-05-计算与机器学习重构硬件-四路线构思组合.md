## 一、90 秒版本

`F-P·杨观察`：真正值得借鉴的不是“拿便宜模组做一个场景产品”，而是在设计硬件时就假定后面存在计算、模型或反馈，使旧硬件可以故意少一点、糙一点、弱一点，甚至形成过去无法存在的机器。

两份机制侦察没有证明“AI 重构硬件会产生大量适合杨的机会”，但提供了四个足以展开构思的结构：

1. 人或粗机械负责大范围动作，小执行器闭环修正局部误差；
2. 不替代专家判断，先把专家的采集动作、覆盖检查和结果确认做成实时指导；
3. 设备先粗测，再根据不确定性决定哪里必须补采真实信息；
4. 用宽带、可编程前端和软件模式合并多把专用工具，但优先检查经典 DSP／控制是否已经足够。

本文件把四个结构各展开两个产品构思，共 8 个。它们横跨较近的专业工具改造、中期新硬件和长期主动测量系统，不做跨量纲总排名。

最重要的共同边界是：**计算没有消除精度、信息和责任，只是把它们从大机架、专家手艺或全量采集，转移到定位基准、标定、补采、软件维护和失效处理。**

## 二、共同设计纪律

每个构思都必须同时回答：

- 旧设备靠什么承重；
- 新设备具体少了什么、放松了什么；
- 计算接走哪部分工作；
- 新增了什么、牺牲了什么；
- 失败时是否能停下、退化或要求人工确认；
- 用户购买的是任务结果，还是只觉得技术新奇。

本轮不预设必须使用机器学习。经典视觉、控制、信号处理可以完成时，不因“AI”叙事改用更复杂模型。

## 三、路线 A：局部闭环替代全局机械精度

### A1｜手持式大幅面精准放样／标线器

| 字段 | 当前构思 |
| --- | --- |
| 用户／场景 | `H`：船厂、建筑装修、机电安装、展陈施工人员，需要在船体、墙面、地面或大型板材上标出孔位、切割线、安装轮廓或连续曲线 |
| 当前替代 | 卷尺＋墨线／粉笔；激光投线；纸质模板；全站仪放点；墙面打印机或大型数控设备 |
| 主要变化 | 人负责把设备沿大致路径移动，视觉标记／相机／惯导估计全局位置，小行程 XY 喷点、墨轮或划线头实时修正，使大型曲面不再需要同尺寸机架或完整模板 |
| 已有部分 | `I`：Shaper Origin 已证明“人做大行程＋小执行器纠偏”可以成为商品；市场上也可能已有施工放样机器人、墙面打印和 AR 投影等价方案，当前为 `Ø` |
| 计算角色 | 视觉定位、轨迹配准、局部闭环控制；首版未必需要 ML |
| 我方可能控制 | 结构、定位基准、不同表面耗材、校准流程、施工数据格式与工作流 |
| 新增／牺牲 | 新增定位标记、相机标定、表面适应和耗材；牺牲完全无人值守，操作者仍需推行 |
| 最大未知 | 现场布基准和校准是否比人工量线更费时；曲面、粉尘、反光、遮挡与大尺度累计误差能否控制 |
| 可推翻条件 | 若布设／校准时间加返工风险不低于现有激光、模板或人工放样，或现有投影／施工机器人已等价可得，则该差异不值得选择 |
| 依赖层级 | `H·中期定制硬件＋控制`；不计商业进展 |

### A2｜手持式曲线密封胶／胶黏剂轨迹助手

| 字段 | 当前构思 |
| --- | --- |
| 用户／场景 | `H`：车身维修、门窗安装、船舶舾装、卫浴施工人员，需要沿弯曲接缝打出连续、均匀且位置准确的胶线 |
| 当前替代 | 熟练工手持胶枪＋目测；遮蔽胶带；专用导轨；固定机器人或龙门点胶机 |
| 主要变化 | 人负责粗略沿缝移动，摄像头识别接缝，小范围喷嘴机构修正横向位置；压力／速度闭环同时调节出胶量，使“全行程机器人”降成“手持粗移动＋局部精修正” |
| 已有部分 | 自动点胶和视觉跟踪均已成熟；手持工具中是否已有等价闭环产品为 `Ø` |
| 计算角色 | 接缝跟踪、速度估计、局部纠偏与流量控制；经典视觉可作为基线 |
| 我方可能控制 | 喷嘴机构、胶材参数库、可清洁流道、校准与不同工艺的验收标准 |
| 新增／牺牲 | 新增堵胶、清洗、黏度变化、耗材适配和视觉遮挡；设备不能替代基层处理、打底和最终压缝 |
| 最大未知 | 用户真正困难是轨迹位置、出胶均匀，还是表面准备和收口手艺；闭环带来的改善是否足以抵消清洗维护 |
| 可推翻条件 | 若普通工人借助简单导嘴／胶带已能稳定达到验收要求，或胶材变化让自动控制频繁失效，则不值得增加闭环硬件 |
| 依赖层级 | `H·中期定制硬件＋工艺数据` |

## 四、路线 B：把专家采集动作变成实时指导

### B1｜建筑渗漏／保温异常的引导式巡检棒

| 字段 | 当前构思 |
| --- | --- |
| 用户／场景 | `H`：验房师、物业维修、防水维修人员，在墙面、顶棚、窗边和管线附近寻找渗漏、冷桥或保温异常，并需要留下可复查的证据 |
| 当前替代 | 热像仪、湿度计、含水率仪分别使用；靠经验决定扫哪里、距离和角度；拍零散照片后人工写报告 |
| 主要变化 | 设备先指导覆盖路径和采集条件，实时判断漏扫、反射干扰或温差不足；发现可疑区域后要求贴近测湿／复拍，并自动把测点和现场图对应。第一版只帮助“采得完整、可比较”，不自动宣称漏水原因 |
| 已有部分 | 手机热像附件、测湿仪、验房 App 和报告软件均存在；是否已有把覆盖指导、补测与证据定位连成闭环的等价产品为 `Ø` |
| 计算角色 | 采集质量检查、覆盖地图、条件提醒、补测建议；识别模型只作辅助，不替代最终判断 |
| 我方可能控制 | 巡检流程、测点定位、跨传感器校准、报告证据链和服务标准 |
| 新增／牺牲 | 新增多传感器标定、环境条件记录、责任边界和报告维护；牺牲“拿起热像仪随手看”的简单性 |
| 最大未知 | 专业人员是否真的因漏扫和证据整理损失时间；新手生成的材料是否会被客户、维修方或保险方信任 |
| 可推翻条件 | 若专业用户用现有热像仪＋测湿仪即可低成本完成可靠闭环，或新手即使被指导也无法获得可用证据，则产品价值不足 |
| 依赖层级 | `H·近中期现成模组＋流程软件＋少量结构` |

### B2｜二手车漆面／车身检查的引导式测量套件

| 字段 | 当前构思 |
| --- | --- |
| 用户／场景 | `H`：小型二手车商、流动检测员或高价值二手车买家，需要系统检查漆膜厚度和车身表面，但容易少测、测错位置或无法证明覆盖完整 |
| 当前替代 | 手持漆膜仪随机点测；经验判断色差与缝隙；委托检测门店；查看维修记录 |
| 主要变化 | 手机视觉识别车身区域并引导测量网格，漆膜仪读数自动绑定到具体位置；系统提示遗漏、异常复测和左右对称比较，输出覆盖地图。它只说明“哪里异常／证据不足”，不自动断言事故原因 |
| 已有部分 | 蓝牙漆膜仪、车辆检测 App 和专业检测服务均存在；组合后的等价可得性为 `Ø` |
| 计算角色 | 位置绑定、覆盖检查、异常复测与证据组织；经典规则可先行，ML 不是前置条件 |
| 我方可能控制 | 车型表面分区、测量流程、设备连接、报告标准与历史数据 |
| 新增／牺牲 | 新增车型识别、曲面定位误差、设备兼容和金融／交易责任；检测时间可能上升 |
| 最大未知 | 用户是否愿意完成足够多测点；定位精度能否支持复测；专业检测的低价格是否已经消除独立工具空间 |
| 可推翻条件 | 若人工随机点测已经足以支撑交易，或定位与车型差异导致数据无法复用，则“完整覆盖”不会产生足够价值 |
| 依赖层级 | `H·近期现成仪器＋App／定位夹具` |

## 五、路线 C：不确定性驱动的主动测量与补采

### C1｜电子维修用自适应复检显微台

| 字段 | 当前构思 |
| --- | --- |
| 用户／场景 | `H`：手机、电脑、无人机和小家电维修店，检查 PCB 焊点、连接器、腐蚀、异物和返修质量 |
| 当前替代 | 技师用显微镜逐区查看；拍照放大；高价工业 AOI；故障后再靠电测定位 |
| 主要变化 | 先用低倍率快速拍完整板面，系统只把“不确定、疑似异常或与参考板差异大”的区域送到电动载台复拍，并自动切换倍率、焦点和照明角度。设备输出待人工确认的复检队列，不直接判定维修方案 |
| 已有部分 | 数码显微镜、电动载台、焦点堆栈和工业 AOI 均成熟；面向维修店而非产线的等价自适应产品为 `Ø` |
| 计算角色 | 变化检测、不确定性估计、主动选择下一视野、焦点与照明；必须允许拒绝判断 |
| 我方可能控制 | 小型载台、照明方式、维修板参考数据、补拍策略、技师反馈闭环 |
| 新增／牺牲 | 新增载台精度、参考板数据、误报队列和设备适配；可能比人工扫板更慢 |
| 最大未知 | 小店的板型极其分散，是否存在足够重复性；技师真正耗时是否在观察而非电测和拆装 |
| 可推翻条件 | 若缺少参考数据时误报过多，或熟练技师肉眼扫描明显更快，则主动显微不会改善任务 |
| 依赖层级 | `H·中期定制载台＋视觉模型` |

### C2｜复杂曲面无损检测的“粗扫—补扫”手持探头

| 字段 | 当前构思 |
| --- | --- |
| 用户／场景 | `H`：船厂、复合材料维修、压力设备或大型结构检测人员，在狭小空间和曲面上进行超声／声学／热激励检测 |
| 当前替代 | 按固定网格全量扫查；机械扫查架／爬行器；技师凭经验反复扫可疑处；事后发现数据不足再返场 |
| 主要变化 | 手持探头先做低密度粗扫，位置跟踪把数据拼成覆盖图；系统把低置信度、耦合差或异常边界不清区域变成明确补扫指令，只有取得新的真实数据后才更新结果 |
| 已有部分 | 位置编码扫查、相控阵、全聚焦和 AI 判伤分别存在；把不确定性直接控制补扫的商品化等价方案为 `Ø` |
| 计算角色 | 位姿拼接、数据质量估计、不确定性地图和补扫规划；最终缺陷判定仍由合格人员承担 |
| 我方可能控制 | 探头接口、跟踪结构、扫查协议、补扫逻辑、证据链与特定曲面工艺数据 |
| 新增／牺牲 | 新增跟踪、耦合监测、实时计算、校准、验证和检测责任；粗扫可能漏过模型未见异常 |
| 最大未知 | 补扫是否真的减少总扫查时间和返场；行业标准是否接受非均匀采样；系统如何证明没有因粗扫漏掉承重缺陷 |
| 可推翻条件 | 若合规要求仍强制全覆盖固定网格，或粗扫＋补扫不能在同等漏检率下降低总工时，则该架构没有现实优势 |
| 依赖层级 | `H·长期定制硬件＋算法＋行业验证`；不得因方舟背景提高证据等级 |

## 六、路线 D：可编程前端合并多个专用工具

### D1｜维修人员的可编程声学／振动诊断探头

| 字段 | 当前构思 |
| --- | --- |
| 用户／场景 | `H`：物业、汽修、小型工厂设备维修人员，需要判断异响、轴承状态、泄漏、松动或共振来源，但不会为每种任务购买和学习一台专业仪器 |
| 当前替代 | 机械听诊器、录音 App、振动计、超声检漏仪、频谱仪和老师傅听感 |
| 主要变化 | 用宽带接触式传感器／麦克风、可切换前端增益和统一采集主机覆盖数种任务；软件根据任务切换带宽、采样和显示方式，并引导建立基线、复测和对比。首版不承诺“一键诊断故障” |
| 已有部分 | 各类单功能仪器和手机分析软件成熟；一支探头能否在耦合、动态范围和频段上等价覆盖为 `Ø` |
| 计算角色 | DSP、频谱、同步采集、基线比较；ML 只在有足够同类设备数据时增加异常检索 |
| 我方可能控制 | 探头接口、耦合附件、任务模式、基线库和现场流程 |
| 新增／牺牲 | 新增多模式校准、附件管理和解释负担；通用探头可能在每个任务上都不如专用工具 |
| 最大未知 | 用户需要的是一机多用，还是更信任低价专用工具；不同接触表面和设备造成的数据漂移是否超过可比范围 |
| 可推翻条件 | 若专用工具价格已足够低，或单一宽带前端无法达到各任务最低信噪比和重复性，则合并没有价值 |
| 依赖层级 | `H·中期可编程前端＋经典 DSP` |

### D2｜墙体／铺装结构的可编程激励检测头

| 字段 | 当前构思 |
| --- | --- |
| 用户／场景 | `H`：瓷砖铺装、建筑维修和验房人员，需要检查空鼓、松动、局部脱粘或结构差异，并把敲击经验变成可重复记录 |
| 当前替代 | 空鼓锤＋耳听；手工逐格标记；红外热像；专业冲击回波或雷达设备 |
| 主要变化 | 一个手持头用可控轻敲／振动激励和接触式声学传感，按材料模式改变激励波形与接收带宽；设备记录位置、耦合和响应，先输出“需复测／与邻区不同”的地图，不直接给出结构安全结论 |
| 已有部分 | 冲击回波、敲击检测、墙体雷达和手机声学识别研究均存在；低价可编程手持整机的等价方案为 `Ø` |
| 计算角色 | 激励控制、信号处理、邻区对比、质量检查；只有在取得跨材料数据后才考虑 ML 分类 |
| 我方可能控制 | 激励机构、接触压力、位置记录、材料模式、现场标定和报告形式 |
| 新增／牺牲 | 新增材料差异、接触压力、背景噪声和责任边界；无法仅凭声学结果判断所有深层结构问题 |
| 最大未知 | 不同基层、胶层、厚度和边界条件是否使同一硬件无法通用；人工敲击是否已经足够快且便宜 |
| 可推翻条件 | 若每种墙体／铺装都需独立大量标定，或设备只能复现师傅已经能低成本完成的判断，则不值得产品化 |
| 依赖层级 | `H·中长期定制激励头＋信号处理` |

## 八、最强反例与共同停止线

1. **Shaper 反例**：局部闭环没有消除工业化；定位耗材、逐台标定、执行器和上游主轴仍承重。
2. **Light／Lytro 反例**：新能力和巨额融资不自动产生购买理由；退出原因仍为 `Ø`，不得简化为算法失败。
3. **低场 MRI／Tesla 反例**：删除物理性能或独立传感模态后，算法不能保证恢复未观测信息；必须有任务边界、补采或安全退化。
4. **Butterfly／通用器件反例**：合并专用硬件可能增加芯片、库存和生命周期风险，一机多用不等于净成本更低。

八个构思共同停止于构思孵化。任何对象进入商业深挖前，必须先回答：

1. 本轮具体看哪个产品或用户任务？
2. 什么真实行为说明它被选择过，或为什么原创任务值得直接验证？
3. 哪条信息会改变产品判断？
4. 完成后距离我方方案或真实交易验证近了哪一步？

## 九、组合选择门

本文件新增 8 个满足最低字段的可比较构思，已经触发一次组合选择。选择时只允许四种处置：

1. 点名 1—3 个进入商业深挖；
2. 合并任务或结构高度重叠的构思；
3. 保留但不排队；
4. 关闭当前不值得继续的构思，并保留原因。

选择时分别比较，不做综合分：用户任务强度、当前替代、我方可控制差异、可进入性、验证成本、自然周期和责任风险。

在杨明确选择前，不补全八个构思的市场报告，不建立规范产品卡，不询价、不采购、不打样、不联系真人。
